# 音高与参考线模型（领域规范）

这是本项目最核心的规范。任何涉及音高、参考线、吸附、频率比的改动都必须先读这一份。

## 1. 唯一原则：音高就是频率

音符在底层只存一个 `double frequencyHz`（绝对频率，单位 Hz），不存音级、不存音分、不存 MIDI 编号。

**为什么不用 MIDI 音高 + 音分偏移**：本软件的核心操作是 1:3、1:5、1:7、1:9 这类**非八度比率**。
一个比率为 3 的音与基准音的频率差是 1902 音分，超出任何「MIDI 音高 + 音分」的线性表达范围；
而在对数频率轴上，它只是 `log2(3) ≈ 1.585` 个八度的距离，天然可表达。

MIDI 编号只在**音色窗口的试听小键盘**上出现，且一进入音频引擎就立刻换算成 Hz。

## 2. 纵向坐标：对数频率轴

```
pixelsPerOctave = viewHeight / octavesVisible
y               = centreY - pixelsPerOctave × log2(hz / centreHz)
hz              = centreHz × 2 ^ ((centreY - y) / pixelsPerOctave)
centreY         = viewHeight / 2
```

- 屏幕 y 向下增大，因此**频率越高越靠上**。
- 因为映射是对数的，**等比频率必然等距**：220↔440 与 440↔880 的屏幕距离严格相等。
  这是整个软件视觉逻辑的地基，有单元测试断言。
- 默认 `octavesVisible = 4`（一屏上下共 4 个八度），可在 0.5–10 之间缩放。
- 频率一律钳制在 `[8 Hz, 20000 Hz]`。

可见频率区间：`topHz() = yToFrequency(0)`、`bottomHz() = yToFrequency(height)`。

## 3. 参考线

参考线是「屏幕上一条横线 = 一个频率」的可视化，也是写音符与拖动音符的吸附目标。

### 八度族

给定基准频率 `f0`，其八度族是落在可见区间内的全部 `f0 × 2^k`（k 为整数）：

```
k 从 ceil(log2(bottomHz / f0)) 到 floor(log2(topHz / f0))
```

**没有 n 参数**：不再由用户指定「上下多少个八度」，而是凡落在可见范围内的都显示。
族长度上限 512 条（安全阀）。

### 参考线的三种身份

| 角色 | 默认颜色 | 虚线 | 可交互 | 含义 |
| --- | --- | --- | --- | --- |
| 音符自身族（所属状态未改色，比率为 1:2 时） | `0xff5fd2c8` | 否 | 是 | 基准 |
| 音符自身族（比率非 1:2 时） | `0xff3e6f6b` | 是 | 否 | 已降级，仅作参照 |
| 目标频率族 | `0xff7fe0a0` | 否 | 是 | `f0×r` 与 `f0÷r` 两个族 |
| 手输「赫兹」族 | `0xff7f8fb0` | 否 | 是 | 来自参考线控制栏的 `＋` |
| 参考线组 | 各圆点的颜色 | 否 | 是 | 应用参考组得到 |

**颜色可以被状态覆盖**：参考线状态上有一个颜色按钮，改过之后该状态的全部线条（含八度族）
统一用所选颜色，虚线样式保留但透明度降低；没改过时按上表的默认角色配色。颜色以调色板索引
存储，Core 层不引入 `juce::Colour`。

注意「可交互」只约束**点击写音符**；**拖动音符时所有可见参考线（含虚线族）都是合法吸附目标**，
否则比率为非 1:2 时音符自身的族全为虚线，音符将无法被移动。

### 四类参考线状态

参考线由**参考线控制栏**（编辑栏右侧）里的一串有序「参考线状态」决定，每条是四类之一：

| 类型 | 类型文字 | 内容 | 数量 |
| --- | --- | --- | --- |
| 第一类 | 赫兹 | 一个手输频率 `f0` 及其八度族 | 可有多个 |
| 第二类 | 选中音符频率-选中比率 | 该音符自身八度族 + `f×r`、`f÷r` 两条目标族 | 同时最多一条 |
| 第三类 | 参考线组 | 应用参考组得到的逐圆点频率族 | 可有多个 |
| 第四类 | 选中多个音符 | 每个选中音符各自的一个八度族 | 同时最多一条 |

- **第二类与第四类互斥**，且**锁定项优先**：已经锁定一条第二类时，选中多个音符也不会生成第四类。
- 第一类与第三类是长期的，二、四类跟着选中音符走；**锁定**后二、四类改用锁定那一刻的频率快照，
  不再随选择变化。
- 隐藏的状态不绘制、**也不能在上面写音符**（不参与命中测试），但仍然是拖动吸附的合法目标。
  独显（互斥单选）会把其余状态强制隐藏。

### 生成顺序与去重

按面板里**从上到下**的顺序展开各状态；重复频率只保留**先加入**的那条。
于是当一条手输频率恰好落在另一条状态的八度族上时，按更靠上那条状态的样式与颜色绘制。

## 4. 频率比

界面上写作 `1:N`，语义是 **N 倍频**。

| 按钮 | 文本 | 乘数 r | 快捷键 |
| --- | --- | --- | --- |
| 1 | 1:2 | 2 | `1` |
| 2 | 1:3 | 3 | `2` |
| 3 | 1:5 | 5 | `3` |
| 4 | 1:7 | 7 | `4` |
| 5 | 1:9 | 9 | `5` |
| 6 | 自定义 | 用户输入 | `6` |

- `1:2` 即八度，此时目标频率与自身八度族重合，因此**不额外画目标族、自身族保持实线可交互**。
- `r = 2` 是唯一的「八度模式」，判断用 `isOctaveRatio(r)`（容差 1e-9）。

**频率比是视图状态，不是音符数据**：它只描述「当前选中的这一个音符正按哪个比率看」，
每次音符选择变化都会复位成 `1:2`，也不随工程保存。所以同一个音符被重新选中时永远从 1:2 开始，
新写下的音符也不会继承上一次用过的比率（音符只存频率）。只有恰好选中 1 个音符时才能改比率；
选中多个音符时这一行整体隐藏。

自定义比率接受 `3`、`1:3`、`3:1`、`1/3` 四种写法：

```
parseRatioText("1:3") = 3      // a:b -> b/a，因为 1:3 表示 3 倍频
parseRatioText("3:1") = 1/3
parseRatioText("3")   = 3
```

格式化走 `formatRatioText`：整数比率输出 `1:N`，比率小于 1 时输出 `N:1`，其余输出 `1:小数`。

## 5. 目标频率

选定比率 r 后，以选中音符频率 `f0` 为基准：

```
上目标频率 = f0 × r
下目标频率 = f0 ÷ r
```

两个目标频率各自的**八度族**都显示出来并参与交互，颜色与自身族不同（见上表）。

具体例子（f0 = 220 Hz，r = 3，可见范围 110–1760 Hz）：

- 自身族（虚线）：110、220、440、880、1760
- 上目标族：660（1320、2640 超出可见范围）
- 下目标族：73.33 低于下界，实际显示 146.67、293.33、586.67

## 6. 吸附

### 写音符

在参考线附近（垂直命中带 ±6 px）左键拖动：

- 音高 = 该参考线的频率（精确值，不吸附到别的线）
- 起止时间吸附到当前吸附网格
- 没有水平位移时，默认时值为 1 个网格单位

### 拖动音符

- 横向：按当前吸附网格平移
- 纵向：吸附到**拖拽开始时冻结的**可见参考线集合中距离鼠标最近的一条
- 「最近」是对数距离，即比较 `|log2(线的频率) − log2(鼠标频率)|`。
  其几何含义是：两条相邻参考线的分界线是它们的**几何平均**。
  例：440 与 880 的分界是 622.25 Hz，而不是算术平均 660 Hz。
- 拖动过程中参考线冻结，音符自身的八度族不会跟着音符跑。

### 多选与八度移动

- 多选拖动：由**最后选中的音符**（`AppState.primaryNoteId`）决定倍率 `m`，
  组内所有音符 `频率 ×m`、`起始 tick += Δ`，因此组内音程关系不变。
- `Shift+↑` / `Shift+↓`：所有选中音符 `×2` / `÷2`，结果钳制在 8 Hz–20 kHz。

### 拖动吸附的直接后果

默认 `1:2` 且「输入」为空时，屏幕上只有选中音符自身的八度族，
所以**拖动只能按八度移动**。要按其他音程移动，需要：

1. 在参考线控制栏里按 `＋` 加一条「赫兹」参考线，它的八度族会成为额外的吸附目标；或
2. 选一个非 1:2 的比率，两条目标频率族会成为吸附目标。

这是模型的直接推论，不是缺陷；若将来要改成自由移动，需要同时修改本节与 `04-ui-spec.md`。

### 钢琴窗模式：另一套吸附目标（第十八批）

编辑栏可以切到**钢琴窗模式**（`view.editorMode == piano`）。它不改数据模型，只换**纵向的吸附目标**：

- 纵向是一组**半音行**：12 平均律，`f(k) = 440 × 2^((k − 69)/12)`（`music::piano`，
  A4 = MIDI 69 = 440 Hz）。行高在对数轴上天然相等（一个半音就是 1/12 个八度）。
- 写入与纵向拖动都**量化到最近的那条半音行**；因此 660 Hz（1:3）在钢琴窗里写成 659.26 Hz（E5），
  切回参考线模式后它就是那个半音频率——**不保留原来的任意频率**，这是模式本身的语义。
- 横向（时间）吸附、时长、多选倍率、`Shift+↑/↓` 八度移动的规则**与参考线模式完全一样**。
- 参考线仍然显示，但**不参与写入与吸附**（也就是不再出现在上面的「冻结集合」里），
  悬停比率箭头也不画。视图在切入时对齐一次，使画布上下边缘落在两条行之间。

## 7. 时间模型

- 分辨率 `PPQ = kTicksPerQuarter = 960`，所有时间以 tick（int64）存储。
- 一拍的长度由拍号分母决定：

```
ticksPerBeat = 960 × 4 / denominator
```

  例：4:4 → 960 tick/拍；6:8 → 480 tick/拍。

- 速度 `bpm` 的含义是**每分钟多少拍**（拍 = 分母对应的时值）：

```
secondsPerTick = 60 / (bpm × ticksPerBeat)
```

- 每小节 tick 数 = `ticksPerBeat × numerator`。
- 吸附网格 = `ticksPerBeat / snapDivisor`，`snapDivisor ∈ {1, 2, 4}`，默认 1。
- 因此**音符最短长度 = 一个吸附单位**；默认 1 拍时，1 拍长的音符无法再从左边缩短，
  把吸附调到 1/2 或 1/4 拍即可做更细的长度调整。
- 节拍标记（`TempoMarker`）横向生效到下一个标记之前；换算时必须分段，不能拿单一 bpm 算全曲。
- 所有 tick 与秒的互换都必须经过 `music::TempoMap`。

## 8. 参考组（已实现）

参考组是本软件对「音高系统」的表达方式：**只记录几类音高之间的比率，不记录任何绝对音高**。
因此同一个参考组可以套用到任意音符上。

### 线段与坐标

- 线段代表**恰好一个八度**，两端各一个圆点（下端点位置 0，上端点位置 1）。
  由于八度等价，这两个端点代表的是**同一个类**。
- 圆点的位置 `p ∈ [0,1)` 表示这一类比下端点高 `2^p` 倍。
  位置到频率比的换算就是 `positionToRatio(p) = 2^p`；反向为 `ratioToPosition(r) = fold(log2(r))`。
- 因为所有频率都折算进一个八度，`×3` 落在 `log2(3) mod 1 = 0.585`，`÷3` 落在 `0.415`，
  两者互为镜像（`0.585 + 0.415 = 1`），线段永远不需要延长。
- 两个端点圆点**恒存在、恒可选中，但不存入数据**。内部圆点按位置升序存储，颜色为 8 色色板的索引。
- **两个端点是两个独立的可选对象**：下端点位置 0、上端点位置 1，选中状态按精确位置比较，
  **绝对不能做八度折叠**——`foldPosition(1.0) == 0.0` 会把八度的两端折成同一个条目，
  于是「选中两个端点来等分整个八度」这件事就做不到了（早期版本正是栽在这里）。
  端点在界面上分别标注 `1.000` 与 `2.000`，把「同一个类、不同位置」直接写出来。
- 端点的颜色存在 `ReferenceGroup::frameColourIndex`（默认 7 号灰）。两个端点是同一个类，
  所以**共享一个颜色**；选中任一端点后点色板即改它。应用参考组时，端点产生的那条参考线取这个颜色。
- 线段视图可以缩放：缩小时按八度周期重复显示圆点与叉点（直观体现「同一类音高」），
  放大时回到一个八度便于对齐。

### 叉点（临时预览层）

叉点不是数据，是**预览**：它们表示「将要建立哪些圆点」。

产生叉点的两种方式：

1. **选中一个圆点 + 选择一个比率 r** → 在 `p ± log2(r)` 两个位置上生成叉点（位置相同则去重）。
   不需要基准音。
2. **基准音模式** → 每个选中音符都在线段上投影出一个叉点，位置为
   `fold(基准圆点位置 + log2(音符频率 / 基准频率))`。

清除规则：**任何会改变当前选择的动作**（选中或取消选中圆点、切换模式、点比率按键、执行等分、
点应用或保存预设）都会清掉上一批叉点；唯独「点击叉点把它变成圆点」不清掉同批其他叉点，
否则等分之后想连着确认几个就得重新等分一次。

实现上要小心：这条规则意味着「变成圆点」这次**文档变更**不能触发清空。
`OctaveLadder` 的变更回调必须区分广播来源——只有来自选择状态（`AppState`）的变更才清空叉点；
来自文档的变更只剔除那些「位置已经变成圆点」的叉点（避免叉点压在圆点上）。

### 等分

选中两个圆点（`Ctrl+点击` 多选）后输入整数 `n > 1`，在两点之间生成 `n−1` 个等距**叉点**。
注意两个端点的位置是 **0 和 1**（不是 0 和 0），所以划分整个八度是正确的 —— 早期版本在这里
对端点做了八度折叠，把整条线段折成了零长度。

### 基准音

「选择基准音」建立的是一层**辅助关联**，用来把绝对频率投影到线段上：

```
位置(音符) = fold(基准圆点位置 + log2(音符频率 / 基准频率))
```

关联持续生效，期间选中音符变化就重新投影一次（多选时能看到所有音符的落点），
于是可以「播几个音 → 看落点 → 把想要的落点变成圆点」。
**基准音的绝对频率不会被写进参考组**，它只是建立过程中的依托。

### 参考线组

「应用」把参考组与一个具体音符绑定，产出**参考线组**：

```
第 i 条线的基础频率 = 基准音符频率 × 2^(圆点_i 位置 − 被点圆点位置)
```

再按第 3 节的规则展开它在可见频率范围内的八度族。参考线组的成员包括
**位置 0 的端点圆点**（即基准音符自身的类）与所有内部圆点，每条线的颜色取自对应圆点的颜色。

频率在「应用」的那一刻**定格**，之后不随音符移动。

与音符编辑栏那六个比率按键的关系：**并存、各自开关**。后者描述的是「当前选中音符的比率」，
是另一套独立机制。

## 9. 片段与音符的时间基准（重要）

音符不再直接挂在音轨上，而是装在**片段**里，并且 `Note.startTick` 是**相对片段内容原点**的 tick。

- 移动片段因此天然带动它的音符（不需要逐个改写 tick），循环时内容也能按周期平铺。
- 片段的 `lengthTicks` 是它在时间轴上的**窗口**，`loopLengthTicks` 是**一节的长度**（循环周期）。
- **窗口之外的音符保留但不发声**：这一条同时解释了两件事——
  「在编辑栏里写到片段之外的地方」可以写但不响，
  「把片段拉长」能把原来在窗口外的音符露出来。
- 循环时只播放内容里落在 `[0, loopLengthTicks)` 的音符，把它们按周期平铺并裁到窗口末端。
- 绝对时间与片段内时间的换算只在一处发生：`PianoGrid` 读写音符时加减片段起点；
  其余一切（吸附、复制粘贴、参考组投影）都在绝对 tick 上算完再换算。

**跨音轨拖动片段不改变音高**——频率是绝对量，换的只是演奏它的乐器。
## 音符内部的头尾音高（第六十三批）

音符不再只有一个频率点：`frequencyHz` 是头部，尾部由 `tailFrequencyHz` 给出（0 回退到头）。倾斜窗口 `tiltStart…tiltEnd` 外的音高保持端点值，窗口内采用 log2 频率插值：

`hz(t) = head * (tail / head) ^ (u + curve * u * (1-u))`

其中 `u` 是倾斜窗口内的归一化位置，`curve` 范围为 −1…+1。这个形状保证单调、不会越过头部或尾部；头尾同高时曲线保持平直。拆分音符时会把同一曲线重新参数化到两个子音符，内容不因拆分而改变。

连接（tie）只表示“前一个尾部接后一个头部”，音高链在调度阶段展开；VST 的连接仍只发一个音头，但由于插件只接收初始音高，第二段倾斜形状只作为工程标注。
