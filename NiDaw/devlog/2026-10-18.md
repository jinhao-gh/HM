## 第五十三批·健康修复：四个真 bug + 构建/工程债（已完成）

这一批没有新功能，只有"让它更结实"。用户先把上一轮代码通读了一遍，列出两大项：四个真 bug
与四笔工程债；随后要求把这两大项全部完成。

### 一、四个真 bug

1. **缺文件的提示被覆盖**。`GranularEditor::reloadSample()` 与 `SamplerEditor::reloadSample()`
   在文件读不出来时会写「载入失败：找不到音频文件…」，但紧接着
   `updateControlsFromTrack()` 又用文件名把它盖成「xxx.wav　0.00 秒　0 Hz」——用户永远看不到
   真正的错误。改成 `reloadSample()` **返回错误字符串**，由调用方在拼文件名那一行时优先显示它。
   两个编辑器各补一条自检断言（自检 1378 → 1380 项）。
2. **从不关次正规数**。全仓库搜 `ScopedNoDenormals` 是 0 命中：混响尾巴、采样器长释放、
   粒子云的 Hann 窗淡出都会产生 1e-38 量级的数。`PlaybackEngine::renderNextBlock()` 顶部加一个
   `juce::ScopedNoDenormals`，一条覆盖所有乐器与插入链。
3. **文件选择回调捕获裸 `this`**。`GranularEditor` / `SamplerEditor` / `TrackArea` 的
   `launchAsync` 回调都是 `[this, chooser]`：系统文件对话框开着时窗口被销毁就是 use-after-free。
   三处改成 `juce::Component::SafePointer`（这个代码库在别处已经这么用）。
4. **按乐器种类逐项列举的链没有编译期保护**。上一轮"试听一直响"就是 `applyPreview` 的松开
   分支漏了 `previewGranular`。这次把 `applyPreview` 的松开段改成 `switch (kind)`（无 default），
   去掉 `applyLiveEvent` 里会吞掉新枚举的 `default:`，`renderVoices` 用一个无 default 的
   `switch (info.kind)` 映射到内置乐器，`SynthWindow` 的两处 also 改成 switch。以后新增
   `TrackKind` / `PreviewKind`，编译器会点名。

### 二、四笔工程债

1. **头文件依赖跟踪修好了**（这条最值钱）。根因：中文版 cl.exe 把 `/showIncludes` 前缀按
   **UTF-8** 打印，CMake 按 936 代码页解码成乱码，Ninja 的 `msvc_deps_prefix` 永远匹配不上，
   依赖文件全空。试过 `CMAKE_CXX_DEPENDS_USE_COMPILER=OFF`（Ninja 不理会）和在 CMakeLists 里
   设前缀（`project()` 之后覆盖不掉，而且 CMake 读无 BOM 的 CMakeLists 也按本地代码页解码，
   中文字面量会再坏一次）。最终做法：`work/fix_showincludes_prefix.ps1` 在首次配置后把
   `CMakeFiles/<ver>/CMakeCXXCompiler.cmake` 里的那一行改回编译器真正打印的 UTF-8 字节，
   再配置一次；两个构建脚本每次都跑它，并在刚修好的那一次自动 clean 重建依赖库。
   实测：改 `GranularEditor.h` 后**增量 14 秒、只重编 5 个对象**（以前一律 80 秒全量）；
   改 `Core/Types.h` 正确重编 71 个对象。`build_app.bat / build_tests22.bat` 默认增量，
   末尾加 `clean` 强制全量，`make_release.bat` 两个目标都强制 clean。
2. **`work\` 清理**。7.3 GB、13 个 `app-build*`、18 个 `test-build*`、232 个 `selftest*`。
   写了 `work/clean_old_builds.ps1`（保留 app-build5 / test-build22 / release-selftest，
   每条路径都校验是 `work\` 的直接子目录才删，支持 `-WhatIf`）。沙箱不允许我执行递归删除，
   所以脚本留给用户跑一次。
3. **版本控制**。加了 `.gitignore`（忽略 `work/`、`outputs/`、`NiDaw/external/`、日志）并在
   仓库根 `git init`；沙箱对 `.git` 只有读权限，`git add/commit` 需要在用户自己的终端里跑一次
   （`git add -A && git commit -m "初始快照"`）。`git status` 已确认忽略规则生效。
4. **"从第五十二批之前就存在的偶发失败"查清并修掉**。自检会打开**真实音频设备**（本次是
   蓝牙耳机，44.1 kHz / 441 样本），设备线程与测试的手动 `renderBlockForTest` 同时渲染同一个
   引擎——电平和声部数忽大忽小（一次运行里 `active=9`，另一次 `active=1`）。三条修法：
   自检构造 `MainComponent(false, false)` **不开设备**；每个测量段先
   `resetLiveStateForTest()` 清空实时事件队列并停掉所有声部；`simulateMidiDeviceMessageForTest`
   走的是 `MessageManager::callAsync`，**必须先 `pump()` 再渲染**（VST 场景①以前是先渲染再
   pump，音符要等设备线程帮忙才生效——这就是"4 个音只落 3 个通道""16 个通道偶尔报 12"的根因）。
   改完连续跑 3 次自检：**1380 / 0 失败，三次完全一致**。

## 第五十九批：混合合成器闭环（每声部引擎 / FX / 混音器 / 工程文件夹）

这一批把“已经画出来但还没真正工作”的部分接上，目标是让混合器从骨架变成能完成一首曲子的乐器。

### 一、每声部引擎

`HybridSynth` 原来整条轨只有一组滤波、一组包络和一组 LFO；和弦里后按下的音会继承前一个音的
滤波尾巴。现在每个音符是一个 `HybridVoice`，持有自己的双滤波、4 个 ADSR、4 个 LFO 和调制缓存。
波表 / 采样 / 粒子 / 减法引擎新增 `renderVoiceAdding(noteId, …)`，混合器按音符只渲染对应内部声部，
不需要为 16 个音复制 16 套完整引擎。

回归测试用“A + B 的输出减去 A 的输出等于 B 的输出”证明两个音的滤波状态互不影响；17 个音时
只保留 16 个声部，最老的音先被 note-off 再偷走。

### 二、滤波器

滤波类型加了陷波与梳状；`envAmount` 真正参与每声部截止频率计算。陷波用每声部每通道的两级
FIR 零点，梳状用短延迟反馈（延迟 = 采样率 / 截止频率）。主页面两个滤波图上方加了类型下拉，
右键滤波图可以直接分配“包络 / LFO → 截止 / 共振”。

### 三、FX

4 个 `HybridFxSlot` 现在有真正的 DSP：失真、比特压碎、合唱、相位、延迟、混响、三段 EQ、压缩。
放在五源混音之后、轨道插入链之前；旁通与干湿为 0 时逐样本等于干声。槽参数随工程与混合预设保存，
调制矩阵可以把 4 个槽的干湿与两个主参数当作目标。混音器页同屏显示五源、双滤波、FX 与总输出。

### 四、音源编辑

单采样参数加了起点 / 终点 / 交叉淡化；振荡器窗口画整段峰值波形与拖动竖线，拖动一次一条撤销。
粒子模式画整段波形（暗）和引擎上报的实时颗粒散点（时间 × 取样位置）。

### 五、工程文件夹

`ProjectDocument::saveToProjectFolder` 创建 `<工程名>/project.nprj`、`samples/`、`exports/`，
把音频轨片段、单采样、粒子音源复制进 `samples/` 并把保存副本的路径指向副本；界面层的保存命令
改走这条路径，导出默认指向工程的 `exports/`。

### 基线

单元测试 **36 组 / 4832 条**、离屏自检 **1399 项 / 53 张快照**（新增 `52-hybrid-fx.png`、
`53-hybrid-mixer.png`），含真实 VST3 / VST3 效果器段，0 失败。

## 第六十批：混合器主页面重构、齐奏与六 LFO、FX 全量修复

### FX 审计结论

- 合唱原来用 JUCE Chorus，左右声道共用一条调制延迟，听起来偏单声道；改成左右独立延迟线
  （约 12 / 15 ms、90° 相位差、无反馈）。
- 比特压碎的降采样相位原来按块内样本下标计算，块边界会重置；改成槽内持久计数器。
- 相位器原来同样只有一条 LFO；改成每声道四阶全通、右声道 90° 偏移。
- 延迟 / 混响 / EQ / 压缩补了 Mix=0、旁通、有限值回归；失真没有加过采样，作为已知限制。

### 主页面

主页面增高到 1000 × 820：顶部五列音源区，底部左侧包络、右侧上方双滤波、右侧下方 LFO。
主振卡片新增齐奏 / 失谐 / 位置三个旋钮，缩略图点击只切 2D/3D，编辑单独一个按钮。
包络 4 条显式标签，ENV 1 固定音量；LFO 扩到 6 条。两者都有 MS/BPM 模式和拍分数，
图上画引擎上报的实时位置点。

### 引擎

`WavetableOsc` 增加 1–16 齐奏、0–100 音分失谐、离散位置；齐奏在单个内部声部内展开并按
`1/sqrt(n)` 归一化。`HybridSynth::setTempo` 每块接收当前 BPM，BPM 模式在下一块生效。
调制源追加 LFO 5/6，目标追加每个主振的 Position / Unison / Detune；名称集中到 UTF-8 安全函数。
