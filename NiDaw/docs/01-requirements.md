# 需求与已确认的设计决策

## 产品定位

**HM** —— Windows 上运行的音乐编写软件（Cubase 风格），核心特色是**以频率（Hz）为第一公民**的音高系统：
纵向是一条对数频率轴，所有相关频率以「参考线」形式可视化，并可直接在参考线上写音符。

与常规 DAW 的根本差别：音高不是十二平均律音级，而是绝对频率；编辑栏的纵向位置直接对应频率。

> 名称：软件对外叫 **HM**（exe、窗口标题、关于与文件对话框）。C++ 命名空间仍是 `nidaw`、
> CMake target 仍是 `NiDaw`、工程文件后缀仍是 `.nprj`、预设目录仍是 `%APPDATA%\NiDaw`
> —— 这些是内部与历史兼容用的，改名不影响既有工程与预设。

## 原始需求（用户口径）

### 主界面

1. 界面最上方是总控栏：新建 / 打开 / 导出等。
2. 主体左侧是乐器栏：可编辑乐器名称、音量、声相，可新建或删除乐器。
3. 主体右侧是音轨界面：点击可新建音轨，音轨记录乐器演奏的音高、音符起始、力度等信息。
4. 界面最下方是走带控制：控制播放与停止。
5. 点击一条音轨弹出编辑栏。

### 编辑栏

6. 音符以细长方形显示；左右位置对应起始与结束，上下位置对应音高。
7. 滚轮上下移动；Shift+滚轮左右移动；Alt+滚轮上下缩放；Shift+Alt+滚轮左右缩放。
8. 纵向等距节拍线，小节线比小节内的节拍线更粗，节拍线旁标注小节数。
9. 编辑栏最上方细长条是节拍标记轨，左键创建标记，输入拍型（n:n）与速度，横向生效到下一个标记之前。
10. 未选中音符时，没有横向线。

### 参考线与音符

11. 编辑栏右侧是选项栏。第一栏「输入」可填频率，填入后在编辑栏出现对应频率的横向**参考线**。
12. 每条参考线最左边的上侧标注其频率。
13. 用鼠标在参考线附近左键拖动，可在对应水平位置写音符；音符左右吸附节拍线；右键点击音符删除。
14. 左键点击音符可选中，编辑栏上侧出现「音符编辑」窗口，进入**选中音符**状态。
15. 选中状态下，显示该音符频率的参考线，以及其上下若干八度对应的参考线，交互功能相同。
16. 参考线之间的间距与频率成**对数关系**（220↔440 与 440↔880 等距）。
17. 音符编辑窗口显示该音符频率，可修改，音符位置随之改变；可写文字备注，备注在编辑栏可见。
18. 音符编辑窗口偏右侧有六个按键：五个频率比 1:2 / 1:3 / 1:5 / 1:7 / 1:9（快捷键 1–5）与一个自定义（6）。
19. 选择非 1:2 频率比后，「选中音符」上下若干八度的参考线变虚线且不参与交互；
    同时把选中音符频率 ×比率 与 ÷比率 作为两个**目标频率**，显示它们及其上下若干八度的参考线。
20. 每次左键写入音符，选中音符切换为刚写下的音符；点击「锁定音符」后不再切换。

### 参考组（原「率制」，已实现）

核心概念：**相距八度的频率算同一「类音高」**，即 `{f × 2^k}`。

21. 「参考组」是编辑栏左侧一栏，**常亮显示**，不需要点击进入。最上部是「历史」与「预设」两个按钮，
    最下部是「选择基准音」「保存预设」「应用」三个按钮，中间主体是一条代表一个八度的竖直线段，两端各一个圆点。
22. 线段区域：滚轮上下滚动所看的频率区间，`Alt`+滚轮缩放（缩小时可见多个八度的重复图案，放大便于对齐）。
23. 选中一个圆点后选择一个比率，在「该圆点类音 × 比率」与「÷ 比率」的位置生成**叉点**（不需要基准音）。
24. 点击「选择基准音」后，先点线段上一个圆点、再点一个音符，即可把该圆点的类音与音符的类音联系起来；
    此时选中多个音符会在线段上出现它们全部对应的叉点。
25. 叉点是临时预览：下一次改变选择的动作会清除上一批；点击叉点可在该位置建立**圆点**。
26. 选中线段上任意两个圆点后输入大于 1 的整数 n，会用叉点把两点之间等分为 n 份。
27. 参考组**只记录比率信息，不记录绝对音高**；「选择基准音」仅用于辅助建立，不把绝对音高计入参考组。
28. 「保存预设」把当前参考组存入「预设」的「参考组预设」。
29. 点击「应用」后，先点一个圆点、再点一个音符，即把该音符频率与该圆点联系起来，
    算出线段上其余圆点对应的频率（称为**参考线组**），并显示这些频率及其八度族对应的参考线；
    同时在编辑栏右侧选项栏显示该参考线组的状态，可单独关闭。
30. 每次建立参考线组都会存入「历史」；历史条目可直接重新启用，也可「添加参考线组预设」。
31. 「预设」按钮在参考组栏旁另起「预设栏」，可在「参考组预设」与「参考线组预设」间切换；
    预设可改名、删除；参考组预设的「使用」把该组复制到当前线段并清除原圆点，参考线组预设的「使用」即启用它。
32. 圆点可逐个改颜色（8 色固定色板），对应参考线跟随同色。
33. 多选音符时显示全部选中音符的参考线；「参考线锁定」按钮可让参考线常亮。

### 内置乐器

28. 一首用于该 DAW 的 VST 乐器，内置于软件中；由简单合成器组成：正弦 / 方波 / 锯齿 / 三角四种波形，
    可调制包络线，可进行 FM 调制。
29. 必须正确响应编辑栏中音符所对应的音高、起始与终止。

### 追加需求（2026-09-11 第二轮）

30. 选中音符后左键拖动，可把音符移动到参考线上。
31. Shift+↑ / ↓ 把选中音符上移或下移一个八度。
32. 左键拖动音符边缘可改变音符长度。
33. 左键点击时间轴可改变开始播放的位置。
34. 点击乐器弹出音色调整窗口。
35. 选中音符时视图不再自动聚焦（不再把视图中心跳到该音符）。

### 追加需求（2026-09-13 音轨栏片段系统，已实现）

36. 音轨栏做成 Cubase 风格的排列区：顶部是与编辑栏**同步的时间轴与节拍标记轨**，
    下面是音轨条，音轨条上是**片段**。
37. 在音轨条空白处**左键长按后拖动**创建片段；右键删除片段；点击片段即进入编辑栏并打开它。
38. 编辑栏只显示当前打开片段的范围，**超出片段位置与长度的区域不显示**（绘制变暗、不发声）。
39. 拖动片段可移动位置，**片段内音符随之移动**；片段可纵向拖到**不同乐器轨**（音高不变，换乐器）。
40. 片段具备与 Cubase 相同的**可重复与调整长度**能力：右侧中部手柄 = 循环并拉长（内容按一节平铺重复），
    右下角手柄 = 只改长度，左边缘 = 改起点（右边缘不动）。
41. 复制粘贴音符：选中音符后 `Ctrl+C` 复制，`Ctrl+V` 粘贴到**当前时间指示标（播放头）**的位置，
    只能粘在编辑栏。
42. 复制粘贴片段：`Ctrl+C` / `Ctrl+V` 同理，只能粘在音轨栏。
43. 片段**重复 N 次**：`Ctrl+D` 复制一份；选项栏「重复 N 次…」按钮可输入份数。
    副本依次落在源片段之后，遇到已占用的位置就顺延到下一个空位，不删除已有片段；
    一次命令（哪怕 N 份）只产生一条撤销记录。

44. 右侧「选项栏」改名为**参考线控制栏**，用于展示所有启用中的参考线状态，称为**参考线状态**。
    列表初始为空；上方 `＋` 按钮弹出输入频率窗口，确定后出现该频率的参考线，并作为**第一类**入列。
45. 每条状态**分三行**：第一行类型，第二行名称（可自定义），第三行五个按钮。类型文字：
    第一类「赫兹」、第二类「选中音符频率-选中比率」、第三类「参考线组」、第四类「选中多个音符」。
    改第三类的名称**不改变预设中的名称**。
46. 四类：第一类＝手输定频率（可有多个）；第二类＝选中单个音符时的参考线（同时只能有一条）；
    第三类＝参考线组（可有多个）；第四类＝选中多个音符时全部参考线合成的一个整体。
    **第二类与第四类不能同时存在**。
47. 状态划分：选中 1 个音符进入「选中单个音符」，出现第二类；选中多个音符进入「选中多个音符」，
    出现第四类。第二类＝该音符自身的八度族 + 两条目标频率族。
48. 选中多个音符时，「音符编辑」窗口列出**每个选中音符的频率 / 力度 / 备注**，可逐个修改。
49. 每个状态有五个按钮：**锁定 / 解锁**（快捷键 `n`）、**显示 / 隐藏**、**独显**、**颜色**、**删除**。
    隐藏只是不显示（不删除，也不能在上面写音符）；独显把其余状态强制隐藏，再次点击退出；
    颜色可编辑，相隔八度共用同一个颜色；删除即移除该状态。
50. **未锁定**的状态在建立新参考线后被清除；**锁定**的状态：一、三类可以一直存在，
    二、四类不因选中的音符改变而改变。锁定的状态随工程保存。
51. 可以**拖动状态调整上下顺序**，也可以用键盘**上下方向键**在控制栏中选择状态。
52. 删除原来的「锁定为常亮」功能。

### 追加需求（2026-09-13 第二轮反馈，已实现）

53. 参考线状态里的**五个按钮都要有文字**（此前「颜色」「删除」只有提示气泡，是空白按钮）。
54. **频率比是「当前选择的临时设置」**，不是音符的数据：选中单个音符时默认 1:2；
    改了比率、点别的音符再点回来，仍然是 1:2。频率比不随工程保存，新写下的音符也从 1:2 开始。
55. 选中**多个**音符时，**不需要**频率比选项：六个按键、自定义输入框都不生效。
    （2026-09-17 微调：那一行**不再整行消失**，而是留着并置灰，右边写明「选中一个音符时可用频率比」——
    用户反馈「频率比选项不见了」，一行凭空消失会让人以为功能没了。单音符时行为不变。）
56. 音符新增**静音**：开关在音符编辑窗口里（单选那一行，以及多选时每个音符一行）。
    被静音的音符**变灰、不被播放**（实时与导出都不发声），但仍然保留、仍占时间轴位置、仍能选中与拖动。
57. 音符的**备注显示在音符外侧**（音符正上方），不再画在音符矩形内部。

### 追加需求（2026-09-13 第三轮：轨道类型与乐器栏重做，已实现）

58. 轨道有**类型**：合成器 / 采样器 / 音频。点音轨栏左上角的 **＋** 弹出菜单选择类型新建；
    本轮只有「合成器」可用，另两项置灰（引擎分别在后续批次接上）。
59. **删除原来的左侧乐器栏**：乐器信息只出现在**一个**竖栏里——音轨栏每行的**行头**就是乐器条目，
    含名称（就地改名）、音量、声相、「音色」按钮、类型文字、片段数与「删除」。
60. 编辑栏因此从**屏幕左边缘**开始，不再有第二处乐器列表。
61. **新建工程为空**：一条轨道都没有，提示「点左上角的「＋ 新建轨道」开始」；删掉最后一条轨道后同样保持空工程。
62. 轨道类型建立后不可修改（要换类型就删除重建）。

### 追加需求（2026-09-13 第四轮：DX7 式 FM 合成器，已实现）

63. 合成器改成**六运算器 FM 合成器**（DX7 式）：每个运算器有频率比率、失谐、输出电平、
    四段 RATE/LEVEL 包络（R1–R4 / L1–L4）、力度敏感与键盘速率缩放；32 个算法决定谁调制谁、
    谁进输出；运算器 6 可自反馈；另有 LFO（速率 / 延迟 / 波形 / 音高深度 / 幅度深度）与整体移调。
64. 必须**正确响应音符的音高、起始、结束与力度**：载波按音符频率发声，音符起始触发包络的
    R1–R3，音符结束触发 R4，力度既缩放整体输出、又按各运算器的「力度敏感」改变音色。
65. 编辑器窗口分四页：**算法**（32 个算法按钮 + 反馈 + 连线示意）、**运算器**（六个运算器 +
    比率 / 失谐 / 电平 / 力度敏感 / 速率缩放 + 八个包络滑条）、**LFO**、**输出**（增益 / 滤波 / 移调），
    底部始终有 C4–C5 试听键盘。
66. 提供一组**内置 FM 预设**（电钢琴、FM 钢琴、钟琴、管钟、铜管、弦乐、贝斯、马林巴、风琴、
    击弦古钢琴、长笛、铺底、拨弦、打击乐、口琴），可在编辑器里直接切换。预设为本项目原创，
    不使用任何厂商 ROM 音色。
67. 新建一条合成器轨时自动套用电钢琴预设，而不是一个没调过的空音色。
68. 旧工程的简单合成器（波形 + ADSR + 调制比 / 深度）在打开时**迁移成两运算器 FM 音色**
    （算法 1：运算器 1 为载波、运算器 2 为调制器），尽量保留原来的音色性格。

### 追加需求（2026-09-13 第五轮：采样器，已实现）

69. ＋ 菜单里的**采样器**可用：新建采样器轨，在音色窗口里**导入一段音频文件**
    （wav / aiff / flac / ogg / mp3）。
70. 为这段音频设定**基准音高**（这份录音本身是哪个音高），之后音符按
    `音符频率 ÷ 基准音高` 改变播放速度，从而正确响应音高、起始、结束与力度。
71. 采样器可以**调制**这段音频：ADSR 包络、低通滤波（截止 / 共振）、循环（开关 + 循环起止）、
    一个可调速率 / 音高深度 / 幅度深度的 LFO，以及增益。
72. 音色窗口里有**波形显示**（峰值包络 + 循环位置标记）与试听键盘。
73. 采样器轨的工程文件里存文件路径与全部参数（不含音频数据本身）。

### 追加需求（2026-09-13 第六轮：音频轨，已实现）

74. ＋ 菜单里的**音频**可用：新建音频轨时直接问你选一个音频文件，导入后**在音轨栏里以片段形式显示**。
75. 音频片段按文件时长落在时间轴上，可以用和音符片段一样的方式**拖动、改长度、跨轨移动**；
    改左边缘时音频文件里的起点同步平移，声音不会跟着片段一起滑走。
76. 音轨栏的音频片段里画**波形缩略图**；点击片段在编辑栏里显示**只读波形**（不接受写音符）。
77. 音频轨没有音符：播放与导出都直接混这段音频，走同一条渲染路径。
78. 音频片段在工程文件里记**文件路径 + 起始偏移 + 增益**，不内嵌音频数据。

### 追加需求（2026-09-14 第十八批：外部 VST3 乐器，已实现）

117. ＋ 菜单里新增**「VST 乐器」**：选中后先弹出**插件选择器**（搜索框、插件列表、
     「重新扫描」「添加目录…」「确定」「取消」），选好插件才建轨道，取消就不建。
118. **插件扫描是按需的**：打开选择器时若还没有缓存才在后台扫描，结果缓存在
     `%APPDATA%\NiDaw\pluginlist.xml`；附加目录记在同一个目录的 `vstfolders.json`。
     启动时不扫描，也不阻塞界面。
119. 插件的**界面在它自己的窗口里**（非模态、可缩放、全局复用一个窗口）：有自己界面的用
     插件界面，没有的用 JUCE 的通用参数面板。行头上的按钮在 VST 轨上叫「插件界面」。
120. 插件的**路径、名字、唯一 id 与状态块**随工程保存（状态块 base64 内嵌在 `.nprj` 里），
     所以工程是自包含的：换台机器只要有同一个插件，打开工程就恢复同样的音色。
121. 找不到插件时，**轨道保留但静音**，行头类型行显示「VST 乐器 · 插件名（插件缺失）」，
     按「插件界面」可以重新定位 / 换一个插件。

### 追加需求（2026-09-14 第十八批·第二批：编辑栏双模式，已实现）

122. 编辑栏表头多一个**「模式」**下拉：**参考线模式**（原有行为）与**钢琴窗模式**。
     选择随工程保存；鼓机轨与音频轨保持各自的视图（鼓格 / 只读波形），此时模式开关置灰。
123. **钢琴窗模式**：纵向是半音行（12 平均律，A4 = 440 Hz），画布左边一条 44 px 宽的键盘条
     （黑键短一截、每个 C 标音名），切入时把视图对齐到半音行；**写入与纵向拖动都量化到半音**，

### 追加需求（2026-09-25 第四十二批：自定义波表，已实现）

192. **波表可以自己造**：从 WAV 导入、从**当前打开的音频片段**取样、在窗口里**手绘**

     16 位 PCM`；播放用的 mipmap 是**派生数据**，载入后重新生成，不写文件。振荡器用
     `customTableId` 引用（0 = 用内置 `tableIndex`）。旧工程缺字段 → 没有自定义表、照常打开。

### 追加需求（2026-09-24 第四十一批：MIDI 输入 + 录制 + 片段重叠，已实现）

184. **顶栏「MIDI输入」打开一个属于它自己的窗口**：左边是**竖琴键**（**低音在下、高音在上**，
     与频率轴同向），右边是所选**参考线组**的竖线与圆点（**锚点上下各一个八度，共三个**；
     圆点右边写频率、颜色同该组）；把左边的琴键拖到右边的圆点上就完成了绑定，
     右键琴键或连线断开。设备下拉列出机器上的 MIDI 输入设备（外加「（不使用）」），
     选中的设备存 `%APPDATA%\NiDaw\midi.json`（应用级，不进工程）。
185. **循环 / 非循环两种模式**：循环模式只有**一格**（`循环键数` 1–24，默认 12 个半音），
     整格在 MIDI 键盘上**上下重复，而音高跟着键盘升/降八度**——
     `频率 = 格里的值 × 2^floor((音号 − 锚点) ÷ 格长)`，负音号向下折回（`59 / 锚点 60 /
     格长 12` → 第 11 步 ÷2）；**空格步在任何八度都不发声**。
     所以「一格 12 个半音 + 只把 7 个白键连到 7 个圆点」就是 C 大调：按白键出音阶、
     从左到右一路递增（每个八度整体 ×2/÷2）、按黑键不发音。非循环模式是 0–127
     每个音号自己一条，不受这一条影响。
     `应用` 在循环模式里是**学习锚点**（点一个左侧琴键、再按一个 MIDI 键，锚点 = 按下的音号 −
     点的是这一格里的第几个），非循环模式的 `应用` 只是确认。
186. **映射存的是频率数值，不是「第几个圆点」**：以后改参考线组不会悄悄改掉已经教过的映射；
     映射随工程保存（`.nprj` 的 `midiInput` 段，旧工程缺这段 = 空映射），也能存进预设库
     （`presets.json` 的 `midiMaps` 段：保存 / 另存为 / **改名…** / 预设… / 删除）。
     `改名…` 用输入框给存下的那张映射改个名字，**库里的那一条与工程里记的 `presetName`
     一起改**；还没存过预设时提示先用「另存为…」。
187. **弹 MIDI 键盘用「当前选中轨道」的乐器发声**（含 VST，经过这条轨的效果器与推子）：
     走实时音符通道，所以**走带停着也出声**，而**导出里没有它**（导出用另一台引擎）。
     鼓机 / 音频轨不路由 MIDI 输入（没有「频率」可绑），窗口打开时会写明原因。
188. **编辑栏是钢琴窗模式时，MIDI 走十二平均律**（绕过映射），窗口状态行也这么写；
     参考线模式下才走映射。
189. **鼠标写音符会试听**：写下一个**新的**音符时用该轨乐器响一下（260 ms 后自动收尾）；
     移动 / 改长度 / 删除都不发声。
190. **MIDI 录制**：走带栏新增一个「**录制 / 停止录制**」按钮（平时写「录制」，
     武装时写「停止录制」并变红）与「片段内 / 片段外」切换，
     快捷键 `*`（主键盘与小键盘都认）；武装**不自动起播**——走带跑起来以后按下的琴键才落成音符。
     **片段内**：写进当前打开的片段（起点按当前「吸附」量化），播放头越过片段末尾就把
     `lengthTicks` 撑到覆盖新音符（循环周期不动）；**片段外**：第一个音新建一个片段，
     长度铺到本次录制的最后一个音。**一个音一条撤销记录**（`录制 MIDI`），按下到抬起算一条；
     录制期间照旧经实时音符通道发声，所以「听到什么就录下什么」。
191. **片段之间可以重叠**：新建片段与拖动片段都不再裁掉邻居（`music::trimOverlapsInTrack`
     与它的两处调用一起删掉），重叠的地方**两段一起发声**（调度本来就是「把这一轨所有片段的
     音符展开后一起发声」）；可见性维持「后建的画在上面、点最上面的那条」。
     粘贴仍然先找空位。重叠片段的视觉分层（comping）记入待办。

### 追加需求（2026-09-25 第四十三批：声音被硬切，已实现）

197. **插入链跟着尾巴走**：乐器最后一个声部的释音结束、这条轨「不活跃」之后，**只要这条轨有
     插入效果器**，引擎仍然跑下去——效果器继续 `process`、继续并入总输出，直到这一块真的
     静下来。判据是**连续 8 块**（512 帧 @48k ≈ 85 ms）的峰值都低于 **−100 dBFS**，
     之后才回到「跳过这条轨」的老路。没有插入效果器的轨道照旧立刻跳过（零开销）。
     副作用（想要的）：尾巴放完之前，混音台上这根电平表会继续跟着落。
198. **停止自然放完、跳转截断、循环不截断**：`停止` 只释放声部并把位置拨回播放起点，
     **不重置任何插入链**——混响 / 延迟的尾巴继续响完；**跳转**（拖播放头 / `Home` / 打开工程）
     仍然重置每条插入链（否则延迟线会重放跳转之前的声音）；**循环回卷**本来就不重置，保持原样。
199. **对外部 VST 用真正的 note-off，而不是 CC123**：宿主乐器新增
     `HostedInstrument::releaseHeldNotes()`，`HostedPlugin` 对每个还按着的音符发一条**真的
     note-off**（不发 all-notes-off、不 `channels.reset()`），并且**保留尾巴计时**，于是
     插件的释音与它自己的混响照常衰减。`allNotesOff()`（note-off + CC123 + reset）只留给
     「确实要立刻安静」的场合：换工程 / 卸载插件 / 槽位换乐器。
200. **再按播放会把上一次停止留下的尾巴掐断**：走带从「停着」重新开始时，引擎**硬**放掉
     所有声部（外部插件收到 `allNotesOff`）并**冲掉每条插入链**，所以新的一遍从安静开始，
     不会叠在上一次的混响 / 延迟尾巴上。**停止本身仍然不掐断**（尾巴照旧响完），而且
      **正在播放时再按播放不是重开**，什么也不掐断。

### 追加需求（2026-09-25 第四十四批：MIDI 输入的缩放 / 滑动与「一键多连线」，已实现）

201. **一个钢琴键可以连多个圆点**：映射里每个键存的是**一组频率**（空 = 不发声）。拖琴键到
     圆点是**加**一条连线而不是替换；**右键琴键**断掉这个键的全部连线、**右键一条连线**只断

202. **右侧那一列可以上下缩放和滑动**：`1×` = 全览（整组铺满画布，原来的样子）；**滚轮**滑动

     指哪放大哪）、**双击**回到全览；滑动被夹在内容范围内（滑到边就停，不会滑出画布），

203. **右键的目标判定放宽**：右键琴键时**整行**都算那个键（黑键那半行右侧原来是空白，现在也认，

### 追加需求（2026-09-25 第四十五批：外部 VST 多音互相拉音高，已实现）

204. **一个音一个通道，而且通道不能马上被收回**：一个音符独占一个 MIDI 通道（音分靠该通道的
     pitch bend 补）。通道的取用次序是**先用从没用过的**（最小号优先），十六个都用过之后才用
     **释放最久**的那个——插件还在那个通道上放着上一个音的释音，越早释放的音尾越短，被新音
     的弯音带走的痕迹就越小。这样「柱式和弦连弹」会先把十六个通道铺满，而不是每次都挤在
     0–3 号上把上一和弦的音尾拉走。
205. **实时音符与工程音符各用一套编号**：工程音符的编号是每轨 1、2、3…（调度器自己编的），
     实时音符（MIDI 键盘 / 屏幕琴键 / 写音符试听）一律翻译进一个**私有的负数空间**
     （`kLiveNoteIdBase`）再交给乐器。两套编号从此不可能相同——否则乐器会认为这是「同一个音」，
     让它们共用一个通道（一条弯音），实时音的 note-off 还会把工程音符的通道提前收掉。
206. **十六个通道用完时，掐掉最老的音**：抢通道之前先给被抢的那个音发一条**真正的 note-off**
     （它照常释音、自然收尾），而不是让它继续响着、被新音的弯音拉走。被抢的音自己迟到的
     note-off 找不到通道，因此不会误杀新音。
207. **通道级的 CC 要跟着音走**：踏板 / 表情这类控制器是「这个通道的状态」，而现在每个音
     各自在一个通道上，所以一个通道**第一次拿到音**时要把已发出的控制器值补发一遍，
     不然「先踩踏板、再起一个音」里的那个音永远收不到踏板。

### 追加需求（2026-09-25 第四十五批·修正：按半音演奏 + 插件弯音诊断，已实现）

208. **有些插件把 pitch bend 当整机的，HM 得给它们一条退路**：实测（用下面那个诊断工具）
     Serum 2 就是这样——一条弯音会把**所有**正在响的音一起拉走，而 Pianoteq 9 是按通道的
     （一个音动、另一个不动，且弯音范围正好是 HM 声明的 ±2 半音）。所以每条 **VST 轨**可以
     单独选「**按半音演奏（插件把弯音当整机时用）**」：打开后这一轨的音一律落在**最近的半音**
     上，**不再给任何音单独的弯音**（发的是正中间的值，等于不弯）。代价是丢掉 1:3 那类精确
     频率，换来的是「和弦不再互相拉音高」。默认关（老工程行为不变），随工程保存。
209. **入口**：在**音轨行头上点右键**（任何位置）→ 勾选/取消那一项；它是一次可撤销的编辑
     （`VST 按半音演奏`），引擎在下一次调度重建时就用新频率。
210. **诊断工具**：`HM.exe --vstprobe <插件.vst3> [--out <目录>]` 会加载那一个插件、在两条
     通道上用两个不同的弯音弹两个音，量出每个音**真正**落在什么频率上，并写一份报告
      （`vst-pitch-probe.txt`）：插件是按通道弯音还是整机弯音、它有没有接受 HM 的弯音范围
      （RPN 0）、以及它自己有哪些和弯音 / 通道有关的参数。这是"为什么这个插件的音不对"的
      第一手证据（本轮就是靠它把 Serum 2 与 Pianoteq 9 分开的）。

      内置轨由引擎处理（`CC11` 乘在这一轨的输出上，所以混音台电平表跟着掉；`CC64` 踩着时
      **实时音符的 note-off 也被挂住**，抬起才补发）。其它控制器一律转发给 VST。
      弯音轮**不在这一批**（它和「每个音独占一个通道的精确音分」会互相打架）。
218. **弹奏的控制器会录进片段**：录制武装且走带在跑时，`CC64 / CC11 / CC1` 的每一次变化都写进
      这一趟落点所在片段的**控制器曲线**（片段相对 tick，按现有吸附量化）。撤销粒度是
      **一个控制器一次手势一条**（「录制控制器」）：推表情推出一串值也只算一条，安静 300 ms
      或这一趟结束就算手势结束。走带停着时只在实时发声，不写工程。
219. **虚拟键盘窗口**（顶栏「虚拟键盘」/ `Alt+K`）：一条能一次看全的 **88 键钢琴**
      （A0–C8），点、按住拖动、电脑键盘（下排 `Z S X D C V G B H N J M` = C…B，上排
      `Q 2 W 3 E R 5 T 6 Y 7 U` 高一个八度，`-` / `=` 换八度）都能弹；左边是力度控件
      （1–127），键盘上写着键位对照。它**与硬件 MIDI 键盘完全同一条路**：参考线模式走映射、
      钢琴窗模式走十二平均律，录制 / 琶音 / 锚点学习 / 高亮全部共用；硬件弹的音在这个窗口里
      也亮着。它**只在拿到焦点时**接管电脑键盘，所以 `1–6`、空格、`*` 在别处一字不变。
220. **琶音器**：速率（`1/4 … 1/32` 含三连 + 自由 Hz）、方向（上行 / 下行 / 上下 / 下上 /
      随机 / 按弹下顺序）、八度 1–4、Gate 5–200%、Swing 0–75%、力度（固定 / 按演奏力度 /
      递减）、Hold/Latch、开关。**只作用于实时输入**（硬件键盘与虚拟键盘），生成的音符走
      现有实时音符通道，所以听得到、录得到，也照旧过该轨的音量与效果器；踩着的踏板照旧
      把它们挂住。**走带跑着时**步进锁在工程位置上（跟着小节与速度变化），**走带停着时**用
      它自己的时钟（从按下的第一个键起算），所以不按播放也能试听。控件同时出现在虚拟键盘
      窗口与 MIDI 输入窗口，同一份状态。
221. **录制琶音时录下的是琶音后的音符**：起始 tick 与长度取琶音本步的**意图值**（格 tick 与
      Gate × 步长），不是音频块量化后的到达时刻——所以听到的稍有块抖动、录进片段的却是整齐的；
      一个音一条 `录制 MIDI` 撤销。琶音设置随工程保存（`.nprj` 的 `midiInput` 段，缺字段 = 关），
      也随 MIDI 映射预设一起走；它是**配置**，不进撤销栈。

### 追加需求（2026-10-06 第四十八批：虚拟键盘的卡音修复 + 折叠置顶 + 巴扬模式与电脑键盘图示，已实现）

222. **修「松开了还在响」**：虚拟键盘里**按住一个键再换八度 / 换布局 / 折叠 / 关窗**时，
      JUCE 按「算出来的音号」记账的那套会留下一个**永远等不到 note-off** 的旧音（同一个键还会
      变成"死键"）。现在这个窗口**自己记下它发起的每一个音**，任何结构性变化都先**经键盘状态
      把它们放掉**（于是引擎真的收音），再重装键位表（顺手清掉 JUCE 的记账）；窗口关闭 / 销毁
      同样先放音。**只放这个窗口发起的音**——硬件键盘正按着的音不动。
223. **折叠成小窗 + 置顶**：折叠后窗口收成 **520 × 120** 的小板（只留一行控件 + 电脑键盘图示，
      键盘条与琶音面板藏起来），再点一下展开回 **980 × 460**；一个「置顶」开关让窗口浮在
      HM 自己的窗口与别的程序之上。两件事都随会话记住（见需求 228 的存档）。
224. **巴扬模式 · 旋律排**：电脑键盘布局多一个「巴扬」。三排字母键按**列**各管三个连续半音，
      于是键盘上写出来的顺序 `q a z w s x e d c r f v t g b y h n u j m i k , o l . p ; /`
      就是**一路半音往上**（30 个键 = 30 个半音）；默认 **`w` = C4**（于是 `q` = A3、`/` = D6）。
225. **巴扬模式 · 低音排**：数字排那 14 个键 `· 1 2 3 4 5 6 7 8 9 0 - = Backspace` 是左手低音，
      按**五度圈**排（上五度下四度：`5` = F3、`6` = C4、`7` = G3 …），整排**折返在 C2–C4
      两个八度**里，14 个键互不重复、永远不越界。
226. **两排各有自己的移位**：旋律排 `半音 ◀ ▶`（±1，范围 ±11）与 `八度 ◀ ▶`（±12，范围 ±3）；
      低音排 `半音 ◀ ▶`（±1）、`五度 ◀ ▶`（±7）与 `八度 ◀ ▶`（±12——第五十一批加的，
      可移范围见需求 237）。
      两排互不影响、切换布局时都保留。
227. **电脑键盘图示 + 钢琴上的字母**：窗口里画一张**真实错位的电脑键盘**（数字排含 `·` 与
      `⌫`、三排字母键），每个键帽按它对应的**钢琴键**上色——**白键画白、黑键画黑**，帽里写电脑键、
      下面小字写音名，没映射的键画成淡灰、按着的键高亮；同时在**上面的钢琴条**上把电脑键字母
      写在对应的琴键上（一个琴键可能写着两个键，例如 C4 上是 `w·6`）。
228. **虚拟键盘开着时，`1–6` 不选频率比**：那六个键在巴扬模式下是低音排、在常规模式下也有
      数字键在弹音，所以只要虚拟键盘**在屏幕上**，`1–6` 就一律不触发频率比；**窗口关掉立刻恢复**。
      音符编辑栏上的比率**按钮**（鼠标）不受影响，`空格` / `*` / 方向键等其余快捷键也不受影响。
      折叠 / 置顶 / 布局 / 两个偏移 / 力度存 `%APPDATA%\NiDaw\keyboard.json`（缺字段 = 默认），
      窗口位置不记。

### 追加需求（2026-10-06 第四十九批：卡音断根 + 键盘随时可弹 + 钢琴变窄 + 低音排严格交替 + 每来源独立声部，已实现）

229. **卡音断根**：电脑键盘的弹奏不再依赖"钢琴组件自己有焦点"（JUCE 那份按音号记的按下表
      一旦漏掉一次 key-up 就永远清不掉，表现就是"松开了还一直响"）。现在**面板自己**在
      `keyStateChanged` 里轮询当前布局的每个映射键，并有一个 **100 ms 心跳**：① 发现自己以为
      按着的键其实已经松开 → 补一条 note-off；② 窗口（含子件）失去键盘焦点 → 整批放掉。
      结构性变化（移位 / 换布局 / 折叠 / 关窗）照旧先放音。
230. **只要虚拟键盘窗口在，就能直接用电脑键盘弹**：焦点在窗口里**任何控件**上都行（面板是它们
      的祖先，键盘事件会沿父链上浮），不用先点一下钢琴键；窗口激活时面板自己把焦点拿过来。
      唯一的例外是焦点在**文本框**里（力度数值框）——那时按键归文本框，与"空格让给文本框"同一条
      规则。
231. **钢琴条变窄**：从 190 px 收到 **90 px**，展开的窗口从 460 收到 **360 px**（电脑键盘图示
      仍拿到约 142 px）；折叠小板仍是 520 × 120。
232. **低音排改成严格的"上五度、下四度"交替**：`· 1 2 3 4 5 6 7 8 9 0 - = Backspace` 两两
      之间一次 `+7`（上五度）、一次 `−5`（下四度），锚点 **`5` = F3、`6` = C4**；整排是
      `·=F#3 · 1=C#3 · 2=G#3 · 3=D#3 · 4=A#3 · 5=F3 · 6=C4 · 7=G3 · 8=D4 · 9=A3 · 0=E4 ·
      -=B3 · ==F#4 · ⌫=C#4`（C#3–F#4），不再有"连着两个上五度"。
233. **每条来源各自持有声部**：同一个音被两条来源同时按着（旋律键与低音键、硬件键盘与电脑键、
      鼠标与电脑键）时**各响一个声部**，各松各停——音域重叠因此不再是冲突。触发源编号：
      硬件 `0`、鼠标 `1`、电脑键 `100 + 键码`；同一(源, 音)的重复 note-on 仍然忽略。
234. **电脑键盘的多键同时按**：按住多个电脑键时**每一个都要出声**（`z / x / c` 一起按 = 三个音）。
      电脑键的弹奏改为**定时轮询**：窗口在屏幕上时每 33 ms 按当前布局读一次系统的键状态，不再只
      依赖"按键事件正好送到面板"这一条路。状态行在有键按着时**列出系统真正报告按下的键**
      （`系统报告按下的键：Z X C`）。
235. **"没有焦点"不等于"失焦"**：只有**别的组件**拿着键盘焦点才把这一批音放掉；一个从没被点过、
      谁也没有焦点的窗口不因此放手。
236. **一次按键三条音**：`z / x / c` 一起按就是三个声部，松开其中一个另外两个继续响；三个都松开
      才静下来（这一条是"按多个键只响两个"那个报告的回归断言）。
237. **低音排的八度按钮**：低音排另有 **`-12` / `+12`** 两个按钮，把整排上下挪一个八度；它和
      `半音 ±1`、`五度 ±7` 共用同一个偏移量（两排仍然各管各的）。可移范围改成**钢琴允许的范围**
      （整排 C#3–F#4，`-28 … +42`），不再卡在 ±11。
238. **粒子合成器**：新的轨道类型（`TrackKind::granular`，**追加在最后**，老的 0–6 序号不动），
      从**导入的音频文件**里撒颗粒。每轨 16 声部、每声部最多 32 颗颗粒（满了丢这个声部里最老的
      一颗）；颗粒窗形**固定 Hann**；颗粒的播放速率 = **音符频率 ÷ 根音**（和采样器同一条算式，
      所以参考线系统的精确频率照样成立）。走带停着也能弹，插入效果器链 / 推子 / 声相 / 电平表 /
      MIDI 输入（力度、踏板、表情）/ 录制 / 导出与其它内置乐器完全一致。
239. **颗粒云的位置**：`位置 + 扫描速度 × 已按下时长 + 位置包络 × 包络量`，超出 0–1 时**折返**
      （到端点掉头往回走，不是跳回另一头）；每颗颗粒再按「位置抖动」随机散开，「音高抖动」与
      「反向概率」各自作用在**单颗**上。密度决定每秒撒几颗，粒度决定每颗多长，间距抖动给颗粒间隔
      加随机量。
240. **音源只存路径**（与采样器一致）：工程与预设记 `filePath` / `fileName`，**不内嵌音频**；
      文件不在时这条轨静音、不崩，编辑器写明找不到文件。没有音源时 `isActive()` 保持 false。
241. **粒子合成器只有用户预设**：**不做工厂预设**（颗粒源在用户硬盘上，工厂预设点下去必然没
      声音）；预设行是「我的粒子音色 N」+ 保存 / 另存为… / 重命名… / 删除，和采样器一样。
      预设连**文件名**一起存，换机器要重新指一次文件。
242. **粒子编辑器单页 780 × 640**（比其它乐器页高，和波表页一样走"按页取高度"）：预设行 →
      文件行（导入音频… + 文件名）→ **波形 + 只读实时颗粒散点** → 参数网格（四列）→ 试听键盘；
      散点 30 Hz 刷新，只在画面真的变了才重绘。散点**不接鼠标**（要改位置就拖旁边的滑块）。

## 已确认的设计决策

下列决策来自 2026-09-11 的需求沟通，均已确认；改动它们需要同步更新本文档与相关实现。

| 编号 | 决策 | 理由 / 取舍 |
| --- | --- | --- |
| D1 | 技术栈 C++20 + JUCE 8.0.15 + WASAPI，原生 Windows | 低延迟、能真正产出插件；放弃 Electron 方案 |
| D2 | 乐器与音轨**一对一**，同一对象既是乐器栏条目也是音轨条 | 模型最简单，等同 Cubase 乐器轨 |
| D3 | 音高在底层存**绝对频率 Hz（double）** | 参考线/目标频率/参考组全部基于 Hz；MIDI 音高+音分无法线性表达 1:3 之类比率 |
| D4 | 纵向是**对数频率轴 + 自动取景** | 等比频率必然等距；`autoFitView` 默认关闭（见 D16） |
| D5 | 取消 n 参数，改为「凡落在可见频率范围内的八度族全部显示」 | 避免多一个参数；与对数轴自洽 |
| D6 | 六个频率比按键全部纳入第一阶段 | 是软件的灵魂 |
| D7 | PPQ = 960，吸附网格可在 1 / 1/2 / 1/4 拍间切换，默认 1 拍 | 对应「音符左右吸附节拍线」并可细分 |
| D8 | 合成器为**软件内置模块**，不产出独立 VST3 | 用户选择；内核与界面解耦以便将来打包 |
| D9 | 合成器规格：单振荡器四波形 + ADSR + 单 FM 调制器 + 复音 16 | 对应「简单合成器」；后追加低通滤波器（D17） |
| D10 | 音频后端先 WASAPI，ASIO 后置 | 零额外 SDK 依赖，最快能出声 |
| D11 | 走带含播放 / 停止 / 回到开头 + 播放头 + 小节:拍:tick 读数 + 速度 | 基础可用性 |
| D12 | 第一阶段含 JSON 工程保存与 WAV 离线导出 | 用户要求 |
| D13 | 撤销/重做从第一阶段就做（快照式） | 编辑器没有撤销很难用 |
| D14 | 编辑栏采用**主窗口内下方展开**（Lower Zone），非独立窗口 | 不用管理多窗口，便于截图与调试 |
| D15 | 音轨条显示**音符缩略预览**（非音频波形） | 成本低、信息足够 |
| D16 | 选中音符时**视图不再自动平移**（`autoFitView` 默认 false） | 拖动音符时画面会跑，无法操作 |
| D17 | 合成器加**低通滤波器**（截止 + 共振），每声部一个，默认截止 20 kHz 即全开 | 用户要求；默认值保证旧工程音色不变 |
| D18 | 修饰键分工：**Ctrl = 多选切换**，**Shift+拖动 = 锁定主导轴**，Shift+↑/↓ = 八度移动 | Shift+点击原本也能多选，与轴锁定冲突，故收归 Ctrl |
| D19 | 拖动音符的纵向吸附目标是**拖拽开始时冻结的、屏幕上全部可见参考线（含虚线族）** | 虚线族在“不参与交互”的语义下仍需要作为拖动目标，否则非 1:2 时无法移动音符 |
| D20 | 拖动过程只画预览，松手才写文档；一次拖拽 = 一条撤销记录 | 撤销栈不被逐帧拖动淹没 |
| D21 | 多选拖动时由**最后选中的音符**决定倍率，其余音符按同一倍率移动 | 保持组内音程关系 |
| D22 | 时间轴定位放在**独立的标尺细条**（节拍标记轨下方），不复用标记轨 | 两个功能挤在一起容易误操作 |
| D23 | 播放中点击时间轴**不停顿**，直接从新位置续播 | 便于边听边调 |
| D24 | 音色窗口是**非模态独立窗口**，全局复用一个实例 | 可一边调音色一边在编辑栏改音符并试听 |
| D25 | 小键盘用**标准 C4–C5**、A4 = 440 Hz 的十二平均律换算 | 最熟悉；参考组相关的试听留待以后 |
| D28 | 参考组线段**恒为一个八度**，比率折算进 `[0,1)`；两端圆点恒在、恒可选中但不入存储 | 比率与八度等价本就是一个概念，线段无需延长 |
| D29 | 参考组只存比率；参考线组才绑定绝对频率（在「应用」时定格） | 参考组可复用，参考线组是具体结果 |
| D30 | 叉点是**临时预览层**，由「改变选择」的动作清除；点击叉点变圆点不清同批其他叉点 | 否则等分后想连点几个就得重新等分 |
| D31 | 等分产生**叉点**而非直接产生圆点 | 与「叉点是预览」一致，可先看再挑 |
| D32 | 预设存**应用配置目录**（`%APPDATA%\NiDaw\presets.json`），工程文件不存预设 | 预设要跨工程复用 |
| D33 | 历史是**本次会话**的内存记录（上限 50 条） | 长期保存走预设 |
| D34 | 选项栏里每个参考线组可显示/隐藏与删除，且可同时启用多个 | 便于叠加比较不同音系 |
| D26 | 试听走**独立预览声部**，不进入离线导出 | 导出的 WAV 必须与工程内容一致 |
| D27 | 音高单位 20 Hz–20 kHz 为可用范围，纵轴可视范围 8 Hz–20 kHz | 兼顾极端比率与安全 |
| D35 | 音符装在**片段**里：`Clip` 持有 `notes[]`，音轨持有 `clips[]` | Cubase 的心智模型，移动/循环片段天然带动内容 |
| D36 | `Note.startTick` 改为**相对片段内容原点** | 移动片段、循环平铺都只需换算，不必搬动每个音符 |

| D208 | **每条来源各自持有声部**：`MainComponent` 的音符记账从"一个音一条"改成"一个(触发源, 音)一条"，源编号 = 硬件 `0` / 鼠标 `1` / 电脑键 `100+键码`；同一个音被两条来源按着 → 两个声部、各松各停。同一(源, 音)的重复 note-on 仍然忽略 | 低音排（C#3–F#4）与旋律排（A3–D6）**有意重叠**（用户选了 F3 锚点，并明确"两个都要"），而原来"一个音一条"的模型让两边互相打断（先松的那一方把音收掉）。改成每源一条之后，重叠不再是冲突；保留"同一源重复忽略"是为了继续挡住某些硬件键盘的重复 note-on（那才是真正会造出卡音的东西） |
| D209 | **电脑键的弹奏改成"事件 + 30 Hz 轮询"双保险**：窗口在屏幕上时，面板每 33 ms 按当前布局读一遍 `KeyPress::isKeyCurrentlyDown`（Windows 上就是 `GetAsyncKeyState`，即驱动报告的真实状态），与自己的"按着"集合做差分；事件那条路照旧保留 | 这条链路已经被"事件没送到"咬过三次（焦点不在钢琴、焦点落在窗口本身、漏掉的 key-up）。轮询的代价是每 33 ms 约 30 次键状态查询（可以忽略，且空闲时不做任何别的动作），换掉的却是**整类**"某个事件被谁吃掉"的问题——包括"按住三个键只响两个"里属于软件的那一半 |
| D210 | **状态行在"有电脑键按着"时列出系统报告按下的键**（`系统报告按下的键：Z X C`），静态界面一字不变（快照也不变） | 用户报的是"按三个只响两个"，而软件侧已经被自检证明 N 个键都能出声（三个键 = 三个声部）。把**系统真正送来的键**写在屏幕上，是唯一能当场分开"键盘的 key-rolling 有限，第三个键根本没送到 Windows"和"软件把它吞了"的证据；它只在按下时出现，不按键时状态行与以前完全一样 |
| D211 | `focusIsInsideWindow()` 里"当前没有任何组件有焦点"算**在内**（只有焦点明确落在**别的**组件上才放掉） | 常驻轮询让"没焦点就整批放掉"从"漏事件时的兜底"变成"每 33 ms 执行一次"，而离屏自检里根本不存在真焦点：原来那条会把刚按下的音打掉。真实世界里"用户去了别的窗口"这条路仍然是"焦点在别的组件上"，规则没有放松 |
| D212 | **低音排的移位范围改成"钢琴允许的范围"**（`bassShiftRange()` 由偏移表与 A0–C8 算出来：`-28 … +42`），并新增 **`-12` / `+12`** 两个八度按钮 | 原来的 ±11 是**折返版**低音排留下的：那一版整排折在 C2–C4 里，再往上挪 12 个半音折回来还是同一组音，按钮按下去"看着动了、其实没变"，所以当时才卡住。第四十九批把低音排改成**固定的偏移表**（无折返）之后，`+12` 就是一个真正的八度，±11 反而挡住了用户要的操作。现在按 `ShiftRange` 本来该有的含义（"这一排还能挪多远才跑出钢琴"）算：整排最低的 `1`（C#3）与最高的 `=`（F#4）在两头刚好顶到 A0 / C8；旋律排本来就是这么算的，两排现在同一套规则 |
| D213 | **颗粒用固定的 Hann 窗，并按重叠量做音量补偿**：每个颗粒的生命里乘一条 `0.5 - 0.5cos(2πt)`，整条云的输出再乘 `1/√(密度 × 粒度)`（重叠数夹在 1…32） | 两个理由。① 窗形固定：本批不做"颗粒窗形可选"，Hann 没有旁瓣突变，云叠起来不炸也不咔。② 补偿：密度 100 颗/秒 × 粒度 500 ms 就是 50 颗同时响，不补偿的话把密度拧大等于把音量拧大 25 倍；按重叠量的平方根缩一下，密度是"质地"而不是"音量" |
| D214 | **扫描到端点折返**（`fold01`：0→1→0→1），不是循环也不是停住 | 折返让"扫描速度"是一个连续可听的来回，颗粒永远不会突然从文件尾跳到文件头；停在端点会让位置包络没有落脚的地方，循环则会在一瞬间把读取位置甩到另一端（颗粒虽小，尾巴听起来是"跳了一下"） |
| D215 | **音源只存路径、不做工厂预设**（与采样器完全一致） | 采样器当年就是按用户要求把工厂预设撤掉的：音源在用户硬盘上，工厂预设只带参数与名字，点下去必然没声音——那种"坏掉"的预设比没有预设更糟。只存路径则让工程与预设都保持小；代价是换机器要重新指一次文件，编辑器会把真实路径与"找不到"写在文件行上 |
| D216 | **散点图只读，位置由引擎上报**：`GranularSynth` 在控制率发布最多 64 颗颗粒的（位置、年龄），编辑器 30 Hz 读它画点，界面自己不算第二遍 | 和第四十六批波表光标同一条规矩：画出来的必须是**正在发声的那颗**，不是界面的猜测。只读则避免了"在画布上拖一下到底改了哪个参数"的歧义——要改位置有旁边的滑块，一次手势一条撤销 |

### 决策

- **D217**：混合器固定 16 个音符声部；超出时偷最老的音，并先给旧音发 note-off，不让它继续被新音的调制拉走。

- **D219**：FX 属于混合器音色，放在五源混音之后、轨道插入效果器之前；旁通与干湿为 0 时逐样本等于干声。
- **D220**：陷波用两级 FIR 零点实现，梳状用短延迟反馈；两者都跟随每声部的截止频率与包络量。
- **D221**：工程文件夹保存时复制音频源并在保存副本里改写路径；缺失文件不阻止保存，但打开时会明确报告。

## 第六十八批 · 贴近 DX7 的引擎与预设重导入

- **需求 311**：算法扩到 64 条。1–32 保留 HM 自己的路由（旧工程、旧预设不变），33–64 是 DX7 的
  32 条原厂路由；每条都记录反馈落在哪个运算器（多数是 OP6，原厂 2/8/10/12/15/18/20/21/27 不是）。
- **需求 312**：经典引擎按 DX7 的电平语义工作：运算器电平与包络电平都是每步 0.75 dB（99 = 0 dB，
  0 = 静音）；速率 99 约 1 ms、0 约 20 s；力度按每运算器的 0–7 灵敏度折算成电平。包络因此是
  指数衰减，而不是原来的二次曲线。
- **需求 313**：补上 DX7 的键盘与音高参数：键盘电平缩放（断点 + 左/右 -LIN/-EXP/+EXP/+LIN +
  深度）、固定频率模式（1–9772 Hz，不跟随音高）、音高 EG（4 段 R/L，50 = 原音高，范围 ±4 八度）、
  每个运算器的 AM 灵敏度 0–3。
- **需求 314**：LFO 扩到 6 种波形（三角、下锯齿、上锯齿、方波、正弦、采样保持），补按键同步与
  音高调制灵敏度 0–7；PMD/AMD 按灵敏度折算到音分与振幅。
- **需求 315**：`FmPatch::classicEngine` 决定走新曲线还是旧曲线：新工程与 DX7 工厂库默认 true；
  旧工程/旧用户预设没有这个字段，读成 false，声音与第六十七批完全一致。
- **需求 316**：用新引擎重新导入 ROM-1A：算法写 `32 + 原厂编号`，固定频率、键盘缩放、AM 灵敏度、
  音高 EG、LFO 同步/灵敏度全部保留，不再做拓扑近似。

### 决策

- **D262**：算法用追加而不是替换，旧编号不重排；反馈位置放进 `FmAlgorithm::feedbackOp`。
- **D263**：老工程走 `classicEngine=false`（序列化缺字段即旧引擎），新补丁默认 true；界面上不暴露
  这个开关，避免用户把一个音色调成“半新半旧”。
- **D264**：原厂算法 4、6 的反馈跨一条链，引擎按“读反馈的运算器自反馈”近似；其余 30 条的自反馈
  与原厂一致。
- **D265**：电平 0.75 dB/步、速率表、音高 EG ±4 八度、PMD 200 音分、反馈 1 个周期这些常量是按
  DX7 公开参数语义取的近似值，不是 LSI 级仿真；不模拟 12-bit DAC。用 E.PIANO 1 / BRASS 1 /
  TUB BELLS 试听校准。
- **D266**：默认运算器的包络改成 L1–L3 常驻 99。dB 曲线下旧的 85/70 会让新工程的默认音色明显
  偏轻（导出与电平相关的自检会失败）；工厂预设都显式写包络，不受影响。

## 第六十九批 · Minimoog Model D 乐器

- **需求 317**：新增独立的 `minimoog` 轨道类型（追加在枚举末尾，旧值不变），与 FM、减法、波表等
  并列，可创建、保存、读取、导出与试听。
- **需求 318**：引擎按 Model D 还原：3 个振荡器（6 档波形：三角/斜三角/锯齿/方波/宽脉冲/窄脉冲；
  6 档音域 LO/32'/16'/8'/4'/2'；osc2/3 ±7 半音微调）、噪声（白/粉）、混音器与过载、
  24 dB 四极梯形滤波（截止/共振/包络量/1/3 与 2/3 键盘跟随）、滤波与响度两套指数包络
  （起音/衰减/延音电平/释放开关）、振荡器 3 与噪声的调制混合、滑音。
- **需求 319**：音高必须准确：8' 时 A4=440 Hz，16'=220、32'=110、4'=880、2'=1760；±7 半音与
  ±50 音分主调音精确；音符频率（含钢琴卷帘的微分音）直接进入引擎，不做二次移调。
- **需求 320**：复音数可选：单音（后按优先 + legato 滑音）/ 2 / 4 / 8 / 16 / 32 / 不限
  （上限 64 声部）。复音模式每声部独立包络与滤波；超出时先抢已释放的最旧声部。
- **需求 321**：力度响应可调（0–10）：力度影响音量与滤波包络深度；0 时完全忽略力度，还原原机。
  复音数与力度是演奏设置，工厂预设不覆盖。
- **需求 322**：界面按 Model D 实机照片的五段式面板还原：控制器 / 振荡器组 / 混音器 /
  修饰器 / 输出，深色面板 + 木纹边框 + 旋转档位开关 + 拨杆 + 竖轮；上方 HM 扩展条放
  复音数、力度与预设栏。底部木纹键盘区左侧放 LFO 速率 / 滑音 / 衰减开关与 PITCH/MOD 轮，
  键盘在右。外部输入、A-440、耳机、电源、LFO 速率、OSC3 滤波包络、噪声/LFO 画成禁用装饰。
- **需求 323**：内置 30 个预设、6 类各 5（贝斯/主音/铺底/铜管/拨弦与钟/特效），中文名；新建轨道
  默认「经典主音」。

### 决策

- **D267**：单音是默认与原机一致的玩法，但用户要求可选复音，因此 `polyphony` 放进参数并做
  演奏设置；「不限」实际封顶 64 声部（单轨 64 个梯形滤波器是实时余量）。
- **D268**：复音模式不做滑音；滑音只在单音模式生效。改变复音数时释放当前在响的声部。
- **D269**：力度是 HM 扩展（原机没有力度）；`velocitySensitivity=0` 时行为与原机一致。
- **D270**：PITCH 轮只对试听音高临时弯 ±2 半音并回弹，不影响时间线播放；调制轮写 `modDepth`。
- **D271**：梯形滤波使用自写的四极 ladder（输入 tanh 饱和 + 反馈），不直接使用 JUCE 的
  `LadderFilter`（它不开放逐样本 `processSample`）；高共振时靠饱和与输出软限幅保持有界。
- **D272**：复音数/力度变化不写入工厂预设；`applyPreset` 保留当前的复音数与力度灵敏度。
- **D273**：包络的“延音”改为 0–10 电平旋钮（原机是开关）：参数 `*SustainLevel` 0..1，老工程的
  开关值映射为 0.8/0；衰减长短参数仍保留给旧预设（界面不再显示短/长开关）。
- **D274**：面板布局以用户提供的 Model D 实机照片为准（控制器 / 振荡器组 / 混音器 / 修饰器 /
  输出，键盘区左侧为轮子与开关）；照片上有而引擎没有的接口画成半透明禁用控件，不假装可用。
## 第七十批 · 迷你穆格面板重排与演奏扩展

- **需求 324**：面板改为四栏：控制器 / 振荡器组 / 混音器 / 修饰器；去掉最右侧输出栏与底部键盘区、弯音/调制轮和 LFO/滑音/衰减开关。主音量移到顶部栏，做成横向滑条。
- **需求 325**：控制器栏的「振荡调制」换成「齐奏」（UNISON）：三个振荡器各复制三份、分别 -7/0/+7 音分叠加，得到更厚的单音/复音音色。
- **需求 326**：振荡器栏的 RANGE 改名「粗调」、「频率」改名「细调」、「WAVEFORM」改名「波形」；去掉波形旋钮上方的 1–6 数字行，把当前波形中文名放到旋钮上方。
- **需求 327**：混音器的「外部输入」旋钮改为「失真量」（0–10），旁边开关控制通断；去掉右上角过载灯；所有开关与对应旋钮垂直对齐。
- **需求 328**：修饰器栏上下分成两部分：上部「滤波器」六个旋钮（截止 / 共振 / 包络量 / 起音 / 衰减 / 延音），下部「响度包络」三个旋钮（起音 / 衰减 / 延音）；中间三个开关依次为「跟随 1/3」「跟随 2/3」「释键」。
- **需求 329**：「释键」开启时，松开音符的释放时间等于同一条包络的衰减时间；关闭时为 2 ms。
- **需求 330**：所有标签字号放大（面板标签 11.5 px、段标题 16 px、开关 10.5 px），窗口 1120×620，四栏等宽利用空间。
- **需求 331**：滑音开关取消，滑音旋钮 > 0 即启用滑音；预设的 glideOn 仍保留在参数里。

### 决策

- **D275**：UNISON 用三份振荡器副本、±7 音分失谐；复音模式每个声部各自叠加（64 声部时按需限流）。
- **D276**：失真接在梯形滤波之前，`drive = 1.6 + 9.5 × 失真量`，归一化 `tanh` 后送滤波；关时保持原来的 1.5 过载曲线。
- **D277**：「释键」把释放时间接到衰减时间（含衰减长短的 ×0.1），不再固定 80 ms。
- **D278**：去掉底部键盘后，编辑器的试听依赖钢琴卷帘/MIDI；`PITCH`/`MOD` 轮的参数仍保留给预设与时间线。
- **D279**：波形名放旋钮上方，旋钮本身不再画 1–6 数字行，减少与标题的拥挤。
