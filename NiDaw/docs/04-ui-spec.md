编辑栏三根细条（音符编辑条 / 节拍标记轨 / 时间轴标尺）与编辑画布**共用同一套横向映射**
（`pixelsPerQuarter` 与 `horizontalOffsetTicks`），并且都从同一个左边界开始、右侧同样留出
12 px 滚动条宽度，否则刻度对不齐。**新增横条时必须遵守这条。**

**每一栏内部**共用一套横向映射：编辑栏三根细条与编辑画布一套（`pixelsPerQuarter` /
`horizontalOffsetTicks`），音轨栏顶部的时间轴标尺、节拍标记轨与每条音轨上的片段一套
（`EditorViewState` 里的 `arrangementPixelsPerQuarter` / `arrangementHorizontalOffsetTicks`）。
**两栏之间互相独立**（D137）：在编辑栏放大细看时音轨栏可以停在全局概览。

音轨栏的手势：**滚轮 = 纵向滚动轨道**（轨道多到装不下时把下面的轨道滚进视野，向上滚 = 看上面的轨道，
与编辑栏纵向滚轮同向）、**`Shift` + 滚轮 = 横向平移**、**`Alt` + 滚轮 = 以指针为锚点横向缩放**，
缩放范围同样是 8–2000 px/拍。音轨栏不画滚动条（横向纵向都不画），纵向只靠滚轮；
编辑栏另有一套纵向滚轮 / 缩放与两根滚动条。

**这两个手势在行头上同样有效**（第二十九批）：行头里的音量 / 声相推子
`setScrollWheelEnabled (false)`，滚轮不会改值，而是按 JUCE 默认一路上抛到音轨栏去滚动。
以前推子会吃掉滚轮：「滚轮找轨道」路过推子就把那条轨的电平改了，还留下一条撤销记录。

**点击的归属**（第二十九批）：行头容器（`lanesHolder`）只负责裁切，`setInterceptsMouseClicks
(false, true)`——容器自己不收事件、子控件照收；`TrackArea` 与 `LaneHeader` 都
`setWantsKeyboardFocus (true)`，所以点车道空白 / 行头空白时焦点落在它们自己身上，
不会像以前那样被 JUCE 交给「第一个可聚焦子控件」（也就是第一条轨道的名字输入框，
看起来就是「点空白跳进重命名」）。点名字框本身仍然是就地改名。

滚动的车道**只在车道区里画**：行头装在只覆盖车道区的 `lanesHolder` 里，
`TrackArea::paint()` 的车道绘制也被裁到同一块区域——否则滚上来的车道会盖住
「＋ 新建轨道」条、节拍标记轨与标尺（第二十七批修的图层问题）。

**音符编辑栏的槽位是固定的**：编辑栏永远从顶部切出 62 px 给它，画布拿剩下的高度，
所以**画布高度、y↔频率映射、拖动数学都不随选中变化**。选中多个音符时，逐音符列表改成
**压在画布上方的浮层**（`noteEditBar.toFront()`，它的 bounds 越过槽位、盖在画布上），
画布不会被挤压。没选中时栏本身隐藏，槽位里画一行淡字提示。
（这条是用户反馈「框选时弹出音符编辑栏会挤压编辑栏、出现抖动」的修复：
原来选中变化会 `resized()` 画布，框选过程中选中数一直在变，音符就在指针下跳。）

片段里的音符缩略图**按真实刻度画**，并且与引擎用同一个展开函数（`music::expandClip`）：
循环片段是「一个周期的内容按周期平铺」，和它上方的重复分隔线、以及实际发声完全对得上；
拖动片段长度只会多出（或少掉）一整段，已有内容不会跟着拉伸变形。音频片段按文件内容在
真实刻度上画（音频片段不循环，只放一次）。

## 窗口放在屏幕里（所有窗口都遵守）

**规则只有一条：窗口打开时完整落在显示器的工作区里，放不下就先缩小。** 实现集中在
`Source/Core/WindowPlacement.h/.cpp`（纯几何可单测，外加两个「哪块屏幕、多大工作区」的查询），
谁都不许再自己写 `centreWithSize`——它只居中、不检查屏幕大小（D133）。

| 窗口 | 想要的尺寸 | 屏幕放不下时 |
| --- | --- | --- |
| 主窗口 | 1460 × 950（`placement::kMainWindowWidth/Height`） | 取工作区；**最小尺寸也跟着降到工作区**（不降的话约束器会把窗口顶回屏幕外） |
| 琴窗（音色 / 鼓机 / 采样器面板） | 780 × 560（`SynthWindow::kDesignWidth/Height`）；**波表页是 780 × 640**（`kDesignHeightWithWaterfall`，多出的 80 px 给瀑布视图） | 窗口缩到工作区，面板**保持设计尺寸**，窗口出现滚动条 |
| 插件窗口 | 插件自报的尺寸 | 窗口缩到工作区，**插件界面保持自己的尺寸**放在 `Viewport` 里，超出部分滚动可达 |
| 插件选择器 | 600 × 520 | 窗口按工作区缩一次（按钮行在最下面，缩的时候列表先让位） |
| 导出对话框 | 由 JUCE 的 `AlertWindow` 定 | 高度被钳到屏幕内，里面的轨道列表再按屏幕高度收，**「导出 / 取消」永远在窗口里** |

另外两条：

- 窗口开在**它所属窗口所在的那块屏幕**上（`placement::displayAreaFor` 用主窗口的位置查显示器），
  副屏上跑 HM 时弹窗不会再跳到主屏；
- 插件窗口只在**第一次打开**时居中；已经在屏幕上的窗口只被约束（不超出工作区），
  不会被下一次刷新搬回屏幕中央——用户摆好的位置要留着。
- **插件界面永远拿自己的尺寸，窗口跟着它**（D136）：界面装得下时它就是窗口的普通子组件
  （`setBoundsConstrained (窗口内区)`，插件自己的 constrainer 说了算）；
  只有界面比窗口大（屏幕给不了插件要的尺寸）时才把它放进 `Viewport`，
  而且**滚动期间窗口不再追插件**、插件也永远拿不到一个 HM 发明的尺寸。
  **不许**再把「窗口尺寸」和「插件尺寸」互相回推——那会让吸附到固定档位的插件
  （Kontakt 缩放、Serum 的 constrainer）和窗口一直互相改尺寸，表现为界面花掉、点不中。

屏幕边缘统一留 8 px（`placement::kMargin`）；主窗口例外，它可以用满整个工作区（margin = 0）。

### 可写位置起拖：方向决定手势

从**可写位置**起拖时（频率编辑栏里命中参考线 ±6 px、鼓机的鼓垫行），落在哪里并不能
说明想干什么，所以手势由**第一次超过阈值的那段位移**决定，判定一次后整段拖动不再改变：

- **横向为主**（`|dx| > |dy|`）→ **写音符**：频率编辑栏用按下那条线的频率、鼓机用按下那一行的
  `pad`，长度随横向拖动；**不移动的单击**仍然写一个默认细分长度的音符。
- **竖直为主**（`|dy| >= |dx|`）→ **框选**：与空地框选同一条路径，实时更新选择；这次拖动
  **不写任何音符**。

`Ctrl` 不再强制框选，只表示「这次框选与原有选择取并集」（两个编辑栏一致）。
由此，**拖动已有音符**的行为完全不变（竖直拖动仍然是移动 / 鼓机仍然是换鼓，`Alt`+上下仍是改力度），
频率编辑栏的**真正空白处**（没有音符、也没有参考线）也仍然是任意方向都框选。

### 判定阈值（必须保持一致）

- 拖动判定阈值 **3 px**：位移小于它只算点击，不产生移动，避免「想选中却把音符挪走」。
- 拖动方向的主轴判定沿用 `|dy| >= |dx|` 归为竖直（与 `Shift` 轴锁定同一条规则；正好 45° 算竖直）。
- 框选起拖位置有三种：**既不在音符上、也不在参考线 ±6 px 内**的空地（任意方向都是框选）、
  参考线 ±6 px 内但**竖直为主**、鼓垫行上但**竖直为主**。
- 边缘命中带宽 **5 px**，且不超过音符宽度的 34%（很短的音符不会被整个吃掉）。
- 参考线垂直命中带 **±6 px**。
- **长按创建片段阈值 300 ms**，且位移需超过 3 px 才进入创建拖动；300 ms 内松手仍是普通点击。
- 片段手柄命中带宽 **6 px**（右中 = 循环拉长，右下角 = 只改长度）。
- 片段之间**不允许重叠**：拖动或拉伸导致相交时，自动裁剪相邻片段腾出位置。

### 拖动时的视觉反馈

- 移动：原件保持不动，在目标位置画半透明强调色预览与描边，并把将要吸附的参考线高亮。
- 改长度：画出改变后的矩形预览。
- 写音符：画出待写入的矩形预览。
- 框选：以半透明强调色加边框画出选框，并**边拖边更新选中状态**。
- 创建片段：在音轨条上画出待创建片段的预览矩形与提示。
- 移动 / 拉伸片段：画出改变后的片段轮廓预览。
- **预览期间不修改文档**，松手才落盘，因此一次拖拽只对应一条撤销记录。

## 编辑栏的两种模式（参考线模式 / 钢琴窗模式）

表头（30 px）从左往右排：`锁定音符` `吸附 ▾` `纵向取景 ▾` `模式 ▾`（钢琴窗模式下再多一个
`参考线显示` 开关），右端是 `定位选中音符` `关闭编辑栏`。布局按从左到右的顺序分配宽度，
所以窗口缩到最窄（1120 px）时，左边的 `模式` 仍然保持完整宽度。

| 项 | 参考线模式（默认） | 钢琴窗模式 |
| --- | --- | --- |
| 纵向 | 对数频率轴 + 参考线 | 半音行（12 平均律，A4 = 440 Hz） |
| 画布左侧 | 无 | **44 px 键盘条**：白键 `0xffe6e6ee`、黑键 `0xff15151b`（宽度 62%）、每个 C 标音名（9 pt、`dimText`） |
| 行的底色 | 无（只有节拍 / 小节线） | 每隔一个半音一条淡条：白键行 `0xff1c1c23`、黑键行 `0xff202028`；每个 C 再画一条 `gridBeatLine` 细线 |
| 写入 | 从参考线 ±6 px 处横向拖动 | 画布任意位置横向拖动，音高取按下那一行 |
| 纵向拖动 | 框选 | 框选（一样） |
| 移动音符的纵向目标 | 拖拽开始时冻结的可见参考线 | 最近的那条半音行 |
| 参考线 | 参与显示 / 写入 / 吸附 | 只画（默认），不参与写入与吸附；可用「参考线显示」关掉 |
| 悬停比率箭头 | 有 | 无 |

切换模式时视图**对齐一次**：`octavesVisible` 取整到整半音数、`centreHz` 落到半音边界再退半格，
于是画布上下边缘正好落在两条行之间，没有半行。之后的滚轮 / 缩放不再自动对齐。
鼓机轨（鼓格视图）与音频轨（只读波形）没有半音轴，模式开关置灰、保持各自视图。

## 音轨栏与片段

**乐器只在这里显示一次**：音轨行头就是乐器条目（独立的左侧乐器栏已删除），编辑栏横跨整个窗口宽度、
从 x = 0 开始。行头三行：

1. 4 px 颜色条 + 轨道名称（就地编辑）+「音色」按钮；
   就地编辑的三条出口：`Enter` 应用、`Esc` 取消并还原原名、点音轨栏空白处也结束输入；
   应用或取消之后键盘焦点**交还给轨道栏**（否则接着点音轨栏（本身不可聚焦）时光标会留在
   名字框里，看起来像「改完了退不出来」）。
2. 音量滑条（dB）+ 声相滑条（L/R），都带数值框；
3. 类型文字（FM合成器 / 减法合成器 / 波表合成器 / 鼓机 / 采样器 / 音频）+「N 个片段」+「删除」按钮。

VST 轨的两处差别（第十八批）：

- 第一行那个按钮的文字是**「插件界面」**（不是「音色」），点开的是插件自己的窗口；
- 第三行的类型文字是 `VST 乐器 · 插件名`；插件没加载起来时后面再加**「（插件缺失）」**，
  这时轨道保留、静音、仍可改名 / 调音量 / 删除。

- 音轨栏顶部两条（时间轴标尺 + 节拍标记轨）与编辑栏**行为完全一致**，滚轮 / `Shift` / `Alt` 手势也一致。
- 片段以所属音轨的颜色绘制，显示名称、内部音符缩略图，以及循环时的平铺分隔线。
- **片段只允许画在音轨的「内容区」内**（`x >= headerWidth`）。片段矩形的左边界由
  `headerWidth + xForTick (startTick)` 算出，横向滚动后这个偏移会变成负数；不裁切的话，
  片段和它的名称会直接盖到左侧音轨头（乐器名）上。改音轨栏的绘制代码时必须守住这条。
- 在编辑栏里，当前打开的片段是「窗口」：窗口内正常绘制与发声；窗口外的音符保留、可写、可框选、
  可复制，但**不发声**（拉长片段即可露出并启用它们）。
- 没有打开片段时，画布只显示提示，不接受写入与粘贴。
- 片段的信息挪到了音轨栏右侧的竖栏（名称 / 循环开关 / 长度读数 / 重复），见下面「音轨栏右侧的片段竖栏」。
- 片段重复：副本依次落在源片段之后；遇到已占用的位置就顺延到下一个空位，**不裁剪已有片段**，
  因此连按 `Ctrl+D` 会不断把片段阵列加长。一次命令（哪怕 N 份）只占一条撤销记录。

**右键片段弹菜单**（不再直接删除）：`删除 / 切割 / 粘合 / 复制`，不满足条件的项置灰。

| 项 | 行为 |
| --- | --- |
| 删除 | 移除该片段（一次撤销），并清空「当前打开的片段」，编辑栏回到提示态 |
| 切割 | 在**右键点击的位置**切开，切点吸附当前网格；要求离两端各 ≥ 1 个吸附单位。左段保留原 id / 名称 / 循环设置，右段用新 id 与同名。跨切点的音符一分为二（左半保留原 id 只改长度，右半是新 id）；音频片段的右段把文件内偏移推进切点对应的秒数 |
| 粘合 | 与**右侧紧邻**（起点正好等于本片段终点）、**两侧都未开循环**、**都是音符片段**的下一个片段合并；长度 = 两段之和，右段音符按偏移重定位；结果保留被点片段的 id 与名称 |
| 复制 | 放进与 `Ctrl+C` **同一份**片段剪贴板，之后在播放头处 `Ctrl+V` 粘贴 |

菜单项与命令共用同一套可用性判断（`canSplitClipAt` / `findGlueNeighbour`），所以菜单里能点的，
命令一定做得成。

**拖动到边缘自动横向滚动**：写音符、移动音符、改长度、框选，以及片段的创建 / 移动 / 拉伸，
只要指针落在画布左或右边缘 **24 px** 内，视图就按 **12 px / 次、30 Hz** 继续滚动，
并把指针钉在边缘重放这次拖动——所以鼠标停在原地也能一直往右拖。
拖动结束（松开鼠标）立即停止滚动。只横向，纵向不自动滚（免得拖音符时音高跟着画面跑）。

**面板之间的分隔条**：主窗口里音轨栏（上）与编辑栏（下）之间那条是**水平条**，
`StretchableLayoutResizerBar` 必须用 `isBarVertical = false`——JUCE 据此决定读拖动的**纵向**位移。
传 `true` 会让「编辑栏高度」跟着左右拖动变，这是踩过的坑。编辑栏内部那条竖分隔条
（参考组栏 / 侧栏 与画布之间）本来就是左右拖，不动。

**关闭窗口**：有未保存修改时弹「保存 / 不保存 / 取消」。选保存且工程已有文件就直接存盘然后退出；
工程还没存过盘就先弹「另存为」，存成功后从回调里退出，取消则取消退出。
`MainWindow::closeButtonPressed` 与 `systemRequestedQuit`（Windows 关机 / 注销）走同一条检查。
自检里 `showDialogs == false`，这条检查直接放行，绝不阻塞。

## 参考线控制栏

编辑栏右侧那一栏，管的是「现在有哪些参考线」。列表里每一条叫一个**参考线状态**，
三行一条：第一行类型文字，第二行名称（双击可改），第三行五个按钮。
左侧有一条 4 px 的颜色标记（这条状态画线用的颜色），当前选中行有强调色描边，
锁定的行在类型行后面标「［已锁定］」。

| 类型文字 | 含义 |
| --- | --- |
| 赫兹 | 手输定频率及其八度族 |
| 选中音符频率-选中比率 | 选中单个音符时它自己的八度族 + 两条目标族 |
| 参考线组 | 应用参考组得到的一组线 |
| 选中多个音符 | 选中多个音符时每个音符的八度族合为一个整体 |

按钮语义：

- **锁定 / 解锁**（快捷键 `n`）：锁定后不会被下一次新建参考线清掉；二、四类锁定后改用
  锁定那一刻的频率快照，不再随选中的音符改变。
- **显示 / 隐藏**：隐藏只是不画、也不能在上面写音符，条目还在。
- **独显**：只显示这一条，其余强制隐藏；再点一次退出，其余条目恢复各自原本的显示状态。
  独显是**互斥单选**，同时只有一条能独显。
- **颜色**：点开后在该行下面展开 8 色色板，选一个即改色（相隔八度共用同一个颜色）。
- **删除**：移除这条状态。`Delete` / `Backspace` 仍然只删音符，不删参考线状态。

**未锁定的状态是临时条目**：任何一次新建参考线（`＋` 新增赫兹、应用 / 启用参考线组、
以及因选中音符而生成的第二 / 第四类）都会把其他未锁定条目清掉，只留刚建立的那条。
想留住就先按 `n` 锁定。

**列表下方还有一行独立的开关「指示线」**，长得和上面那些状态行**一模一样**：高 54 px、
左侧 4 px 色条（用 `theme::accent`，也就是箭头本身的颜色）、三行内容——
第一行 10 pt 灰字「指示线」（对应状态行的类型行），第二行 11.5 pt 的状态文字
`已显示`（亮色）/ `已隐藏`（暗色），第三行一个 `隐藏` / `显示` 按钮，
槽宽与状态行按钮完全相同、左边缘对齐（按钮文字描述动作：可见时写「隐藏」，隐藏时写「显示」）。
它不是 `ReferenceLineEntry`：不参与列表排序、不能被选中、没有锁定 / 独显 / 删除 / 颜色，
`↑↓` 也选不到它；上方有一条 1 px 细线与状态列表分开，位置固定在列表下方、不随列表滚动。

它只管画布上那个悬停比率箭头能不能看见。关掉之后鼠标停在目标频率线上不再画箭头（也不重绘），
但悬停位置仍然记着，所以再打开时箭头立刻回来。这个开关存在工程里（`view.ratioArrowVisible`，
缺字段的旧工程按「可见」读），切换是一次可撤销的编辑。列表一条状态都没有时，这一行照样在。

## 音轨栏右侧的片段竖栏

音轨栏那一行的最右端有一条 220 px 的竖栏。编辑栏展开时它**上下分成两栏**：
上面是**片段竖栏**（`ClipInspector`，最多 180 px 或竖栏高度的一半，取小的那个），
下面是**效果器栏**（`EffectsBar`，占满剩下的高度）；编辑栏收起时片段竖栏隐藏，
效果器栏自己占满整条竖栏（插入链任何时候都值得在屏幕上）。这一列从音轨栏里切出来，
所以音轨栏变窄，但两边的横向刻度仍然逐像素对齐。

**片段竖栏**放当前片段的信息：名称（可改）、循环开关、长度与循环读数、「重复 N 次…」。
没有选中片段时显示提示。

## 效果器栏（每轨一条 VST3 插入链）

标题行 22 px，写「`效果器`」；选中了轨道时接上「 · 轨道名」，链上有效果器时再补「 (N)」。
标题下面是**可滚动的槽位列表**（竖向滚动条），跟着 `AppState::selectedTrackId` 走——
换选轨道，列表就换成那一条轨道的链。底部固定一行 26 px 的「＋ 添加效果器」按钮
（链满 16 个时置灰）。没有选中轨道时按钮置灰、列表为空。

每个槽位一行 30 px，从左到右：

- **旁路开关**（24 px）：没旁路时写「开」，旁路时写「旁」并用 `theme::playhead`（红）点亮；
  点一下就是一次可撤销的编辑（「旁路效果器」/「启用效果器」）；
- **插件名**（剩下的宽度）：缺插件时写「插件缺失」，这一格还兼做延迟读数——
  插件自报 `getLatencyInSamples()` 大于 0 时补「　·　延迟 N.N ms」（HM **不做延迟补偿**，
  只是把它显示出来，见 D132）；
- **`界面`**（44 px）：打开这个效果器自己的窗口；插件缺失时回到选择器重新定位；
- **`↑` / `↓`**（各 22 px）：在链里前移 / 后移一位（一次一条撤销记录）；
- **`✕`**（22 px）：从链上移除。

空链不画任何行，改画一行居中的灰字「这一轨还没有效果器」。

**顺序 = 信号顺序**：列表从上到下就是声音经过的顺序（上面的先处理，见 D129）。
**推子之前**：乐器 / 音频先过完整条链，再按轨道的音量与声像并入总输出，所以拉音量是在
调「效果器之后的输出」。试听声部与节拍器不过链。链随工程保存（`InstrumentTrack::effects`），
导出与实时监听走同一条路径（D131）。

「＋ 添加效果器」打开的是**效果器模式**的插件选择器：标题「选择效果器」、
只列 `! isInstrument` 的插件，分组树与搜索完全沿用乐器模式（D128）。

## 轨道静音与独奏（M / S）

音轨行头第三行从左到右是 `[M][S] 类型 · N 个片段 ………… [删除]`，两个按钮各 20 × 20：

- **`M`**：这条轨道不发声——不产生音符事件、不产生音频 placement、也不参与渲染长度，
  因此实时播放与导出（含分轨）都不含它。按下时用 `theme::playhead`（红）点亮。
- **`S`**：独奏。**只要工程里有任何一条轨道在独奏，就只有独奏的轨道发声**；没有任何独奏时
  所有未静音的轨道都发声。可以多条一起独奏（叠加）。按下时用 `theme::referenceLineTarget`（绿）点亮。
- **静音优先**：同一条轨道同时按下 M 与 S 时它仍然不发声（与 Cubase 一致）。判定收在一个纯函数
  `isTrackAudible(project, track)` 里，单元测试直接覆盖。
- 与「音符级静音」（音符编辑窗口那个开关）互不影响，两者是「与」的关系。

导出：总混音按听得见的内容写；**分轨导出跳过因 M/S 而不发声的轨道**（不写这个文件，而不是写一个
静音文件），完成提示里会列出跳过的是哪几条。全部轨道都不可发声时，导出会明确说
「所有音轨都被静音或不在独奏状态，没有可导出的声音。」

M/S 随工程保存，参与撤销（一次点击一条记录）。它只影响声音：时间轴范围、片段与音符的编辑与选中、
参考线、循环区间一律不受影响；画面也不做变暗，只有按钮本身的点亮状态在变。

## 音符编辑窗口（多选时）

选中 2 个以上音符时，编辑条**保持原来那 62 px 的两行**（频率 / 力度 / 备注 + 频率比），
下面另接一个可滚动的逐音符列表（每行 22 px，最多 4 行，浮在画布上方）：
序号 + 频率 + 力度 + 备注 + 每行自己的**静音**开关。改哪一项只改那一行对应的音符（各自一次撤销）。
频率比那一行**留着但置灰**（右边写「选中一个音符时可用频率比」），按 `1`–`6` 不改变任何状态——
2026-09-17 之前它是整行隐藏，用户反馈「频率比选项不见了」（一行凭空消失比置灰更像功能没了）。

第一行右端（`静音` 左边）还会出现 **`应用为参考线组`** 按钮：把选中的音符直接定格成一条
第三类**参考线组**——锚点取其中**频率最低**的那个音符（存成位置 0 的圆点），其余音符按
`fold(log2(hz / 锚点))` 折进一个八度各成一个圆点（同音类合并；颜色从调色板 0 起按频率升序分配），
所以画布上出现的是这些频率**及其八度族**。这条参考线组**默认锁定**：随工程保存、不会被下一次
新建参考线冲掉，控制栏里带锁形标记，点「解锁」后变回临时条目。同时它进入**历史**
（参考组栏顶部的「历史」按钮），在那里可以「启用」或「存为预设」。

## 吸附

编辑栏顶部「吸附」下拉有四项：`1 拍` / `1/2 拍` / `1/4 拍` / `不吸附`。它是音轨区与编辑栏
**共用**的同一个值（`EditorViewState.snapDivisor` + `snapEnabled`，随工程保存）。

- 前三个：音符的写 / 移 / 改长度、片段的长按创建 / 移动 / 拉伸 / 切割点，以及两条标尺
  点选播放头，都量化到「一拍 ÷ 细分」的网格。
- `不吸附`：上述操作全部落在**鼠标所在的精确 tick**（只做整数 tick 取整）。细分**被记住**，
  继续决定「点一下不拖」写出的音符长度与改长度 / 切割的最短长度（片段最短仍是 `kMinClipTicks`），
  所以不会出现 1 tick 的意外音符。

## 循环与节拍器

走带栏（底部）在 `|◀ 回到开头` / `▶ 播放` / `■ 停止` 之后是两个开关，再往后多一格「循环」
读数：

- **`循环`**：按下时按钮点亮成 `循环 ●`。区间有效时按它只是开关循环；**还没有区间**时按它
  会把播放头所在的那一小节设成区间并开启，所以按钮永远不会是死的。读数写 `3.1 → 5.1`
  （小节.拍），没有区间时写 `未设置`；开着循环时读数用亮色，关着时用暗色。
- **`节拍器`**：按下后播放时每一拍发一声短促的提示音，**小节第一拍加重**（频率更高、更响）。
  它只走实时监听这条路，**离线导出永远是干净的**（导出用的是另一个引擎实例）。

**划区间**：在音轨栏或编辑栏的**任意一条标尺**上 `Shift`+拖动，拖过的地方就是循环区间，
松手即开启循环；`Shift`+点击（不拖）清除区间。拖动过程中标尺上就有预览块，松手才落盘
（一次撤销记录）。区间按 tick 存进工程，所以改速度时循环点跟着走；隐藏 / 独显之类的
参考线设置与它无关。

**播放行为**：循环开着时，播放走到区间末尾就跳回起点继续（区间内的音符会照原样再来一遍）；
按播放时如果播放头在区间之外，会先跳进区间起点。

## 减法合成器窗口

减法轨的「音色」按钮打开同一个 780 × 560 窗口，显示的是减法页，自上而下：

1. 标题「减法合成器 · 轨道名」+ 与 FM / 采样器同一套**预设行**（`预设 [] [<] [>] [保存为预设…] [重命名] [删除]`），
   内置 12 个原创音色 + 「我的」；
2. **显示条**（高 92 px）：左半是**一个周期的实际波形**（直接用引擎里同一份振荡器函数算，
   所以画面不会和声音不一致），右半是**滤波响应曲线**（按当前模式 / 斜率 / 截止 / 共振算，
   并用较低透明度的竖线标出包络峰值推到的位置）；
3. **四列控件**（行高 21 px，行标题直接画在面板上而不是用 Label 组件）：
   - 列 1：振荡器 1（波形 / 八度 / 半音 / 失谐 / 音量 / 脉宽）
   - 列 2：振荡器 2（同上，标题行右侧的开关控制它的开关）+ 噪声音量
   - 列 3：滤波器（模式 / 斜率 / 截止 / 共振 / 包络量 / 键跟踪）+ 滤波包络 A D S R
   - 列 4：放大器包络 A D S R + LFO（速率 / 波形 / →音高 / →滤波 / →音量）+ 输出增益
4. 底部是 C4–C5 试听键盘，与 FM / 采样器一致。

引擎里的对应关系：每个声部两个振荡器 + 白噪声 → 1 或 2 级 TPT 状态变量滤波器（斜率 24 dB 即两级串联）
→ 放大器包络；锯齿 / 方波 / 脉冲用 PolyBLEP 抗混叠；滤波包络与 LFO 的调制按控制速率（每 16 个采样）刷新。

## 波表合成器窗口

波表轨的「音色」按钮打开同一个音色窗口，显示的是波表页（**这一页是 780 × 640**，
比别的乐器页高 80 px——多出来的正是下面那条瀑布视图），自上而下：

1. 标题「波表合成器 · 轨道名」+ 与 FM / 减法 / 采样器同一套**预设行**（内置 12 + 「我的」）；
2. **3D 瀑布视图（高 168 px，第四十六批）**：把这一张表的 **8 帧沿深度堆叠**画成瀑布——
   0 号帧最近（画得最低最宽），每往后退一帧**水平收缩 3%、抬高 6%**（比例都相对视图高度），
   振幅占视图高的 **30%**；每一帧**填充到自己的中线**（alpha 0.14）再描边，深度轴左端标
   `0…7` 帧号。**当前位置的波形**用 `WavetableSynth::sampleTable`（与引擎共用的同一个函数）
   按相邻帧插值画成一条 2 px 的亮线，落在光标所在的深度平面上——画面上那条亮线就是此刻
   听到的波；一根**实时光标**横跨深度方向，配一个位置读数（`0.42`）。视图顶部一条 22 px 的
   窄条放 **「振荡器 1 / 振荡器 2」**两个切换（各 84 px）与读数：决定这张瀑布画哪一张表。

   振荡器用着自定义表时画面与声音不是同一张——第四十六批修掉）。光标数据来自**引擎上报的
   「真正在发声的声部的位置」**（见 02-architecture），30 Hz 刷新，位置没变就不重绘；
   视图本身可操作：**拖动 = 连续改位置**（一次拖动一条 `改波表位置` 撤销）、**点某一帧的
   深度带 = 跳到那一帧**（位置 = 帧号 ÷（帧数−1））、**滚轮 = 每格 ±0.01**、**双击 = 回到
   0.50**；
3. **四列控件**（行高 20 px，行标题画在面板上，与减法那页同一套写法）：
   - 列 1 振荡器 1：波表（16 张内置） / 位置 / 八度 / 半音 / 失谐 / 音量
   - 列 2 振荡器 2：同上 + 标题行右侧的开关；噪声：音量
   - 列 3 滤波器：模式 / 斜率 / 截止 / 共振 / 键跟踪；位置包络：起音 / 衰减 / 保持 / 释放 / 包络量
   - 列 4 放大器包络：A D S R；LFO：速率 / 波形 / →位置 / →音高 / →滤波 / →音量；输出：增益
4. 底部 C4–C5 试听键盘。

波表页的**窗口高度是 640 px**（多出的 80 px 正是瀑布视图比原来那条显示条高的部分），
其它乐器页仍是 780 × 560；屏幕不够时照旧出现滚动条，不裁控件。

## 粒子合成器窗口（第五十二批）

粒子轨的「音色」按钮打开同一个音色窗口，显示粒子页（**780 × 640**，和波表页一样比别的乐器页
高 80 px——多出来的正是颗粒画布），自上而下：

1. 标题「粒子合成器 · 轨道名」+ **预设行**：只有「我的粒子音色 N」（没有工厂那一栏）与
   保存 / 另存为… / 重命名… / 删除；
2. **文件行**：`导入音频…`（自己的文件选择器，过滤器与采样器相同）+ 文件名 / 时长 / 采样率；
   还没导入时写「还没有载入音频文件」；
3. **颗粒画布（高 140 px，只读）**：先按 `LoadedSample::peaks` 画波形（和采样器同一份数据），
   再把引擎上报的**正在发声的颗粒**画成点——横轴是**取样位置**（0…1，与波形同一列对齐），
   纵轴是**颗粒自己的年龄**（0 = 刚出生，在底部；1 = 快要结束，在顶部），刚出生的点更亮；
   还有一条竖的**扫描线**，画在这些颗粒位置的平均值上。30 Hz 刷新，画面没变就不重绘；
   **画布不接鼠标**——要改位置就拖下面「位置」滑块；
4. **四列参数**（行高 23 px，行标题画在面板上，与减法和波表同一套写法）：
   - 列 1 颗粒：粒度 / 密度 / 位置抖动 / 间距抖动 / 音高抖动 / 反向概率
   - 列 2 取样：位置 / 扫描速度 / 根音；输出：声像扩展 / 增益
   - 列 3 位置包络：起音 / 衰减 / 保持 / 释放 / 包络量；音量包络：A D S R
   - 列 4 滤波器：类型（低通 / 带通 / 高通）/ 斜率（12 / 24 dB）/ 截止 / 共振 / 键跟踪
5. 底部 C4–C5 试听键盘（与其它乐器页共用同一条试听通道，按键盘听到的就是正在编辑的这一份）。

**为什么没有工厂预设**：颗粒的来源是用户自己的文件，工厂预设只带参数与名字，点下去必然没声音
——采样器当年就是按这个理由把工厂预设撤掉的，粒子合成器沿用同一条规矩（见需求 241）。

波表库是**程序内置生成**的只读数据（16 张 × 8 帧 × 2048 采样点），每张表按八度预生成
`1024 → 512 → … → 1` 次谐波的 mipmap，播放时按音高选级，所以高音区不混叠：
帧先以相位形状写出、再做一次正 FFT，随后逐级截断高频并逆变换得到各级波形。
工程里只存 `tableIndex`，不存波形数据本身。

**自定义波表（第四十二批）**：波表页的标题行右端多了一个 **「波表编辑器…」** 按钮
（132 px）。用内置表时点它，会把那张内置表**复制成一张自定义表**（名字「<内置名> 副本」）
并让这条轨的**振荡器 1** 用它，然后打开编辑器；已经在用自定义表时按钮写 **「编辑这张表…」**，
直接打开那一张。

标题行最右端还有一个 **「删除波表」**（92 px），**只在振荡器 1 正用着自定义表时可点**
（用内置表时置灰，因为内置库是只读的）：点它把那张表从工程里删掉，仍引用它的振荡器
（工程里所有轨）退回自己的内置表，编辑器的状态行写明「这张表已经从工程里删掉了，
用到它的振荡器退回内置表」。这是"列出表的地方"（波表下拉旁边）就能删的入口，
不必先打开编辑器窗口。

**波表编辑器窗口**（`Source/UI/WavetableTableWindow.{h,cpp}`）：非模态、可复用、
设计尺寸 **780 × 430**、经 `WindowPlacement`，标题「波表编辑器 · <表名>」。自上而下：

| 位置 | 内容 |
| --- | --- |
| 顶行（26 px） | 名字框（失焦或回车就改工程里那张表）/ `帧数`（1–8）/ `导入 WAV…` / `从片段取样…` / `拷内置…`（弹出 16 张内置表，复制成一张新的自定义表）/ 右端 `试听 C4`、`删除这张表` |
| 主区 | **可编辑画布**：当前帧的 2048 个采样点，横向是位置、纵向 −1…+1，画 1/4、1/2、3/4 竖线与零线；**拖动 = 铅笔**（快拖也补点），**Shift 拖动 = 直线**；右侧 104 px 是 1–8 帧的**缩略图列**（点一下切当前帧，当前帧高亮） |
| 工具行（24 px） | `铅笔` / `直线` / `平滑` / `归一化` / `清空`（每个 62 px） |
| 谐波条（92 px） | 横轴第 **1–64 次谐波**、纵向是量 0…1；进入编辑器或用 `应用` 之后由**当前帧的 FFT** 填充；`应用`（右端 72 px）把当前帧改写成这些谐波的和（加法合成，超出 ±1 才钳制） |
| 状态行（18 px） | 「8 帧 × 2048 点 · 约 32 KB · 第 N 帧 · 一次手势一条撤销」，或一条提示（「这个片段不是音频片段：只有音频片段（有音频文件的）才能取样」/「这张表已经从工程里删掉了，用到它的振荡器退回内置表」） |

窗口**可缩放**，里面那层是**设计尺寸的面板 + 滚动视口**（与音色窗口同一套做法）：
窗口缩到 660 px 宽时，工具栏右端的「试听 C4」「删除这张表」**不会被裁掉**，
而是出现滚动条——每个控件都还够得到。

**波表下拉**（振荡器 1 / 2）：内置 16 张（id 1–16）在前，本工程的自定义表在后
（名字前缀「自定义 · 」）；选中自定义表就把 `customTableId` 写进工程，选内置表则写回
`tableIndex`。下拉里**不放动作**——造表的三件事都在编辑器窗口里。

**撤销粒度**：画布上一次手势（按下到松手）是**一条** `编辑波表`；`平滑` / `归一化` /
`清空` / `按谐波生成波表` / `改波表帧数` / `重命名波表` / `新建自定义波表` /
`删除自定义波表` 各一条 `applyEdit`。

**大小代价**：一张 8 帧表存 32 KB 的 16 位 PCM，base64 进 `.nprj` 后约 43 KB；播放用的
11 级 mipmap（约 700 KB）是**派生数据**，载入后重建，不写进文件。

## 鼓机窗口与鼓格编辑视图

鼓机轨是第六种轨道（`TrackKind::drums`）。它有两处专属界面：

**编辑栏的鼓格视图**（当前轨道是鼓机时 `PianoGrid` 自动切换）

- 纵向不再是频率轴，而是 **12 条鼓垫行**（高 = 画布高 / 12，最少 14 px），自上而下：
  叮叮镲 / 吊镲 / 牛铃 / 高音通鼓 / 中音通鼓 / 低音通鼓 / 开镲 / 闭镲 / 拍手 / 边击 / 军鼓 / 底鼓。
  每行左侧（x = 5）画鼓名，隔行浅底色区分；12 行永远放得下，所以纵向滚动条隐藏、
  「纵向取景」下拉置灰，`centreHz` / `octavesVisible` / 自动取景在这条轨上不生效。
- **写音符**：在某一行按下再**横向拖**就是那个鼓（`pad` = 按下那一行，拖动中不换鼓），横向仍按吸附网格；
  不拖动（单击）就是默认一个吸附单位。**纵向拖动 = 框选**（见上面的「可写位置起拖：方向决定手势」）。
  **Alt + 上下拖动 = 改这一个音符的力度**（0–127，这是拖动已有音符，不受方向规则影响）。
  左右边缘改长度、右键删除、`Ctrl+C/V`、复制粘贴、片段循环展开全都照旧；在已有音符上**纵向拖动仍然是换鼓**。
- **力度直接看得见**：音符矩形的填充亮度按力度取（0 → 45% 亮度，127 → 100%），强弱拍一眼分得出。
- 鼓轨上**不画频率参考线与比率箭头**（纵向是鼓垫，画频率线没有意义），也不做纵向吸附；
  选中音符**不派发**第二 / 第四类参考线条目（频率在鼓轨上没有含义）。
- 音符编辑栏在鼓轨上：频率框变成**只读的鼓名**（如「军鼓」，tooltip 说明音高由音色窗口调），
  比率那一行整行隐藏；力度 / 备注 / 静音与多选列表照旧（多选列表里的「频率」列在鼓轨上显示鼓名）。

**鼓机窗口**（780 × 560，挂在同一个「音色」窗口上）

1. 标题「鼓机 · 轨道名」+ 预设行（**只有「我的」**，存的是整份 `DrumKitParams`）+「恢复默认鼓组」按钮；
2. 左列：**12 个鼓垫按钮**（鼓名 + 开关状态），点哪个就编辑哪个；
3. 右侧：选中鼓的 6 个滑条（开关 / 音量 / 音高 / 衰减 / 音色 / 喳音），旁边是这一鼓的试听按钮；
4. 底部一行：4 个全局滑条（总音量 / 总音高 / 总衰减 / 声场宽度）+ C4–C5 试听键盘
   （60–71 对应 12 个鼓垫，白键黑键都按鼓垫编号触发）。

12 个鼓全部是**程序合成**的，工程里只存参数，不引入采样文件。
鼓是**一次性发声**：音符长度只决定它在格子里的宽度与「掐断」语义（一次闭镲会掐掉正在响的开镲），
不延长声音。音符的 `pad` 决定敲哪个鼓，音高由每个鼓的「音高」与全局「总音高」决定；
**音符的 `frequencyHz` 在鼓轨上闲置**（写音符时填该鼓的基准值，仅作数据占位）。

## 采样器窗口

采样器轨的「音色」按钮打开同一个窗口，但显示的是采样器页（780 × 560），自上而下：

1. 标题「采样器 · 轨道名」+「导入音频…」按钮 + 文件信息（名称 / 时长 / 源采样率）；
2. **预设行**：与 FM 窗口同一套（`预设 [] [<] [>] [保存为预设…] [重命名] [删除]`），
   采样器没有内置音色（预设总得带着它那份音频文件），所以只列出「我的」；
   保存的是**整份采样器音色**（含文件路径）；
3. **波形**（高 90 px）：峰值包络，循环打开时用强调色画两条循环位置标记；
4. 三列控件，**每个参数都有自己的文字**（行标题画在面板上，与减法合成器那页同一套写法：
   分组标题用强调色、参数名用暗色；早先只在每组第一行放一个组名，四个包络滑条底下只有一个
   「包络」，看不出哪个是衰减，这次一并补全）：
   - 左列「素材」：基准音高（20 Hz–8 kHz，对数）/ 循环起点 / 循环终点 / 循环播放（开关）
   - 中列「包络」：起音 / 衰减 / 保持 / 释放
   - 右列「滤波器」：截止 / 共振；「调制」：速率 / 音高 / 幅度；「输出」：增益
5. 底部同样是 C4–C5 试听键盘。

导入支持 wav / aiff / flac / ogg / mp3；工程文件只记文件路径与参数，不内嵌音频。
预设库文件被移动后会像工程一样跳过发声，不做路径重定位。

   有文件读不出来时补「（N 个文件读取失败）」；分组时再补「N 个插件，M 组」）。

窗口 **600 × 520**。分组键见 `01-requirements.md` 的 D128（厂家取 `manufacturerName`，
类型取 VST3 子类别并翻成中文，`其他` / `未知厂家` 排最后）。

**树必须真的装满**（D135）：`RootItem` 的构造函数按分组加 `GroupItem`（分组行自己再挂插件行），
「不分组」时插件行直接挂在不可见的根下。折叠状态用 `juce::TreeViewItem::setOpenness
(opennessClosed)` 存（`setOpen(false)` 在还没挂到树上的 item 上是空操作，会自己弹开）。
**列表为空时不能留一块空白**：在 `paintOverChildren` 里居中写一句
「还没有找到插件：点「重新扫描」扫一遍标准 VST3 目录，或者用「添加目录…」把插件所在的目录加进来。」
（搜索框里有字且没命中时改写「没有名字里带「X」的插件。」）。

第一次打开（缓存为空）时自动在后台扫描一次，界面不卡；选择器里选中的插件名会成为新轨道名。

**插件窗口**（行头「插件界面」按钮打开）：标题「插件 · 轨道名」，非模态、可缩放，全局复用一个实例。
窗口里放插件自己的界面；插件没有界面时用 JUCE 的通用参数面板。插件还没加载完（或加载失败）时，
窗口里显示同一句缘由（例如「找不到插件：<路径>」），而不是一个空框。

**窗口尺寸由插件说了算**（这条是 Kontakt 8「界面显示不全」的修复，见 devlog 2026-09-14）：

1. 打开时窗口取**插件自己报的尺寸**（并把它 constrainer 里的最小尺寸当底线），不再用 HM 的默认
   640 × 420——大界面的插件（Kontakt）会被小窗口切掉大半个界面；
2. 插件**改自己尺寸**时（Kontakt 加载音色库、点它的缩放按钮）窗口跟着变；
3. 能不能拖动窗口边框缩放，由插件的 `AudioProcessorEditor::isResizable()` 决定，HM 不再给插件
   界面强加一个右下角缩放柄；
4. 插件拒绝某个尺寸时（它的 constrainer 不允许），窗口按插件实际定下的尺寸回弹；
5. 窗口**位置**被钳在显示器的可用区域内（照 JUCE 自带 standalone 宿主 的做法），
   免得一开窗就有一半在屏幕外；
6. 插件界面比屏幕还大时（Kontakt 那种大界面 + 笔记本 / 缩放屏），窗口缩到工作区，
   **插件界面保持自己的尺寸放在 `Viewport` 里**——够不到的那部分是滚动可达的，
  而不是被裁掉（D134）；此时**窗口不再跟着插件改尺寸**，插件也不会被塞进一个
  它没要过的尺寸（D136，见「窗口放在屏幕里」那一节）。
7. 插件把自己改小时（Kontakt 缩放调小、切换到紧凑面板）窗口**跟着变小**：
   老代码「不比现在小」的规则会把插件撑回原来的大小，两边会一直互相改。
8. 窗口要的是**界面当前的真实尺寸**（D138）：界面创建后、每次排版后都回读一次，
   插件自己改尺寸时也无条件记录，只有「要不要跟着改窗口」才受回推保护限制——
   过期的尺寸快照会让窗口比界面小、又没有滚动条（用户反馈的「有时候窗口仍然不完整」）。

**外部插件是一台「一直活着」的乐器**（D138）：不管宿主有没有给它发过音符、也不管走带是否在跑，
每个音频块都会调用它的 `processBlock`，所以插件**自带的键盘**（Kontakt / Serum 那种）、
它自己的琶音器与效果尾音都能出声——按播放不是前提。开窗时宿主把键盘焦点交给插件界面
（`setWantsKeyboardFocus (true)` + `grabKeyboardFocus()`），因为插件自带键盘常用电脑键盘演奏。
代价是没有音符时也会占一点 CPU（真 DAW 都这么做）。

**界面只在「自己那个插件换了」时才重建**（D143）：宿主对**每一个**加载完的插件都会通知一次
（`onInstrumentChanged`），所以窗口比较「当前目标实例」与「界面正在显示的那个实例」，
相同时只重排布局、**不拆编辑器**。老代码无条件 `destroyEditor()` + `createEditorAndMakeActive()`：
另一条轨的插件加载完，用户正开着的界面就被拆掉重建，插件会在自己的数值回来之前先画一遍
（推子、旋钮全在零位），缩放与滚动位置也一并丢掉——用户看到的「插件界面有时会混乱或无法控制」
与「内置的音量调节会归为零」都指这里。

**扫描目录**：`VST3PluginFormat::getDefaultLocationsToSearch()`（`%LOCALAPPDATA%\Programs\Common\VST3`
与 `C:\Program Files\Common Files\VST3`）加上用户在「添加目录…」里记住的目录，后者存在
`%APPDATA%\NiDaw\vstfolders.json`，扫描结果缓存在同目录的 `pluginlist.xml`。

**扫描在子进程里做**（第二十九批）：HM 只枚举 `.vst3` 文件（不加载），然后为**每个文件**
起一个自己的副本（`HM.exe --scan-plugin <file> --scan-out <xml>`）去读——那个副本不建窗口、
不初始化音频、写完结果就 `std::_Exit`。每个文件默认 30 s 超时，超时 / 崩溃 / 读不出东西
都算「读取失败」（状态栏那句「（N 个文件读取失败）」里计数），扫描继续。
这一条是必需的而不是洁癖：这台机器上把扫描指向带 Kontakt 8 / Serum2 / FabFilter 的标准目录时，
进程内扫描会让 HM **直接退出**。扫描中状态栏会显示「正在扫描：<文件名>（i/N）」。
宿主**对插件的每一件事**（建 / 毁实例、`prepare`、总线布局、状态写入 / 抓取、`forgetTrack`、
打开工程时的重置）另外记在 `%APPDATA%\NiDaw\plugin-events.log`（上限 512 KB），
用来判定「插件自己的音量被改」这类反馈是谁干的。

## FM 音色窗口

点音轨行头里的「音色」打开（780 × 560，全局复用一个实例，切换轨道时换内容并置顶）。
自上而下：标题「音色 · 轨道名」、**预设行**、**顶层导航行**、当前页、底部固定的
**C4–C5 试听键盘**（白键 `0xffe6e6ee`、黑键 `0xff17171b`，按住即试听）。

**预设行**：`预设 [下拉 ▾] [<] [>] [保存为预设…] [重命名] [删除]`。
下拉分两组：`内置`（十五个原创音色）与 `我的`（用户自己保存的）。条目 id 内置 `1..N`、
我的 `1001+`。`<` `>` 在合并后的整张列表上前 / 后切换；`重命名` 与 `删除` 只在选中「我的」时可用。
`保存为预设…` 输入名字（默认取当前音色名），同名时提示是否覆盖，取消则回到改名；
保存成功会把当前音色也改成这个名字，于是列表高亮的就是它。**FM 与采样器共用这一行**，
采样器没有内置音色，所以只列出「我的」。

**顶层导航行**：`返回` + 面包屑（`算法图库` / `算法 17 · 运算器总览` /
`算法 17 > 运算器 > OP3` / `LFO 调制` / `输出与滤波`）+ 右侧 `LFO`、`输出` 两个入口按钮。

三层下钻：

| 层 | 内容 |
| --- | --- |
| 一 · 算法图库 | 32 张缩略图谱平铺（8 列 × 4 行），每张是方块 + 调制线 + 输出箭头；当前算法套强调色外框。点任意一张 = 选中该算法并进入第二层 |
| 二 · 运算器总览 | 当前算法的大图谱。六个方块按「载波在下、调制器在上」分层（载波第 0 层，其余按到载波的最长路径向上），方块里写 `OPn`、比率、输出电平与「已关闭」，运算器 6 额外标反馈量级；方块右上角一个小开关，点方块进第三层，点小开关切换该运算器的开 / 关 |
| 三 · 运算器详情 | 顶部**包络曲线**（按 R1–R4 / L1–L4 与 `fm::rateToSeconds` 画起音 / 衰减 / 保持 / 释放四段，纵轴用 `levelToAmplitude` 的幅度曲线，标出 L1–L4；只读）；下面左列是比率 / 失谐 / 输出电平 / 力度敏感 / 速率缩放 + `关闭运算器` 按钮（运算器 6 另外多一个反馈滑条），右列是 R1–R4 与 L1–L4 八个滑条 |

**关闭运算器** = 输出置零、参数与连线保留、方块显示为已关闭；引擎里该运算器仍推进自己的包络，
所以按住音符时开关它不会有残留。开关状态随工程保存（`.nprj` 的 `operators[n].enabled`，
缺字段按开启读，旧工程音色不变）。

两个侧页与之前一致：

| 页 | 内容 |
| --- | --- |
| LFO | 速率 / 延迟 / 音高深度 / 幅度深度（0–99）+ 五种波形按钮 |
| 输出 | 增益（0–1）/ 滤波截止（20 Hz–20 kHz，对数）/ 滤波共振（0.1–20）/ 移调（±24 半音） |

滑条拖动一次 = 一条撤销记录（拖动开始压快照，过程中只广播）。图谱本身不写文档，
点图谱选算法、点方块进详情、点小开关切开关才各算一次编辑。

选中 1 个音符时就是原来的那一行（频率 / 力度 / 备注 / 六个比率按键）。
选中 2 个以上音符时编辑条会变高，下面多出一个可滚动列表：每个选中音符一行，
依次是序号、频率、力度、备注；改哪一项只改那一行对应的音符。

编辑条第一行的右端有一个**静音**开关（作用于当前主音符）；多选时逐音符列表每行末尾也有一个，
只改该行的音符。开关按下时用强调色。

## 参考线比率箭头（悬停提示）

第二类（单音符类）参考线在比率非 1:2 时会展开成三族：基准音自己的八度族（**虚线、不可交互**）
与两条目标族（实线、可交互）。鼠标停在**目标族**实线上（沿用 `kReferenceHitSlop` 的 ±6 px 命中带）
时，画一条竖直箭头解释这条线的来历：

- 箭头端（实心三角，宽 9 px、高 11 px）正落在鼠标所指的那条线上；
- 尾端落在「所指频率 ÷ 比率」（`f0×r` 族）或「所指频率 × 比率」（`f0÷r` 族）得到的那条线的高度上
  ——它一定是基准音自己的某个八度线，所以箭头长度恒为 `log2(r)` 个八度；
- 箭杆就在**鼠标尖所在的那一列**、宽 2 px，超出编辑区就裁掉（尾端在屏幕外时照样画，提示"来源更远"）；
  只有指针离左右边缘 10 px 以内时才夹住，避免画到画布外；
- 旁边标 `正 1:3` / `负 1:3`：**向上指向 `f0×r` 族 → 「正」，向下指向 `f0÷r` 族 → 「负」**，
  即文字跟随箭头方向而不是乘法/除法本身；标签**垂直居中于箭头端**（不是箭杆中点，仍受编辑区边界夹取），
  水平方向默认画在**箭杆左侧** 6 px 处——鼠标就在箭杆上，而箭头光标的图形是从热点向右下延伸约
  11 × 19 px，所以只有左侧能保证不被指针压住；左侧放不下时才翻到右侧并把间距放宽到 16 px。
  标签背后垫一块 `gridBackground` 90% 的圆角板（压在音符上也读得清）。

颜色统一用 `theme::accent`（箭头是批注，不是线的一部分，所以不跟随条目的自定义颜色）。
可见箭杆短于 16 px 时不画，避免退化成一个点。第一类赫兹线、第三类参考线组、第四类多音符线
以及 1:2 比率都不出箭头。纯悬停提示：不写文档、不进撤销栈，命中带内按下仍然是"写音符"。

## 导出

`Ctrl+E` 先弹**导出设置**对话框（模态），再按设置选目标并渲染：

| 项 | 取值 |
| --- | --- |
| 格式 | WAV / AIFF / FLAC（本轮不做有损：JUCE 写不了 MP3，见 D96） |
| 位深 | WAV 16 / 24 / **32 位浮点**；AIFF 与 FLAC 只到 24（JUCE 的 AIFF 写入器上限就是 24 位） |
| 采样率 | 工程采样率（默认）/ 44100 / 48000 / 88200 / 96000 / 192000——按所选采样率真正离线渲染 |
| 内容 | 「总混音」勾选框 + 每条轨道一个勾选框，默认全勾 |

- 只勾总混音 → 走「保存文件」对话框，写一个文件。
- 勾了任何轨道 → 走「选择文件夹」，每轨写 `工程名_轨名.ext`，勾了总混音再补一个 `工程名_总混音.ext`；
  非法文件名字符换成 `_`，同名轨道补 `(序号)`，空名字用「未命名」。
- 范围仍是整个工程（最后一个可听音符 + release 尾巴）；整批共用一个进度窗，
  进度按「已写样本 / 总样本」跨文件汇总。
- 分轨渲染走的就是 `buildSchedule (project, onlyTracks)`：与总混音**同一条渲染路径**，只是少了别的轨。
- 渲染前先在消息线程上把**活着的插件状态**抓进一份工程副本（离线实例从它还原），
  所以「插件加载后没存过盘就导出」也是用户正在听的那个音色，而不是插件出厂音色。
- 若这次要写出的轨道 / 插入槽里有**解析不到的插件**（且那条轨真的会出声、在勾选范围内），
  导出**不开始**：弹「导出失败」并列出「轨道名 + 效果器名」，提示去点「插件界面」重新定位。
  被静音或没勾选的轨道不算——用户没要它的声音，不要用别人的插件拦住他。
- `showDialogs == false`（自检）时跳过对话框，用默认设置（总混音 + WAV 24 位 + 工程采样率）。

## 派生的那一行（第二类 / 第四类）的继承规则

第二类「选中音符频率-选中比率」与第四类「选中多个音符」不是用户新建的，而是**跟着选中重新生成**的
（见 `01-requirements.md` 的 D127）。它们**未锁定**时才重新生成，锁定后就定格成普通状态。

- 重新生成时**继承上一行的「显示 / 隐藏」与「独显」**：换选另一个音符、从单个变成多个
  （第二类换成第四类）、先清空选中再选回来，用户设的显示状态与独显都跟着走。
- `独显` 按行 id 记：行还是同一行（选中数量没变）时 id 不变；从第二类换成第四类时 id 会变，
  独显跟着挪到新 id；这一行真的没有了（选中清空 / 换了鼓轨）就清掉，免得它把其余状态全过滤掉、
  画布变成空白。
- 判据只有一条「这一行是跟着选中走的、而且没锁定」，所以显不显示、独不独显都只看它自己。

## 音符的绘制

- 音符以音轨颜色填充；**被静音的音符画成空心**：只画 1 px 轨道色描边、**不填充**，
  这样「在，但不发声」一眼可分。其余规则不变（片段窗口外更淡、选中仍在外面套一圈白色描边）。
  静音不影响选中、拖动与复制，也不影响它在时间轴上的位置。
- **备注画在音符正上方**，左端与音符左端对齐，宽度取到网格右边界，过长省略；用浅色文字
  （`text`，静音音符用更淡的 `dimText`），不再是音符内部的黑字。

## 混音台（第三十七批）

- 入口：顶栏「导出 WAV」右边的「混音台」按钮（提示里写 `F3`），或直接按 `F3`。独立、可复用、
  非模态窗口，标题「混音台」，设计尺寸 **980 × 560**（最小 760 × 420），经 `Core/WindowPlacement`
  收进工作区，关闭只是隐藏。
- 布局：左边是横向可滚动的条带区（一次显示多少算多少），**最右钉住一根总输出条**（不跟着滚）。
  条带宽 **106 px**（第三十七批修正时加宽，为了放得下刻度），高度随窗口；窗口太矮时条带保持
  自己的高度、由滚动条去够，不是把推子压扁。底部一行是 `▶ 播放` / `■ 停止` /
  `|◀ 回到开头` + `小节:拍:刻度` 读数（与走带同步，30 Hz）。
- 一根轨道条带，自上而下：轨道名（带轨道色）／乐器入口（内置轨写「音色」、VST 轨写「插件界面」，
  点开的就是行头那颗按钮开的东西）／插入链（最多 4 行，每行 名字 + 延迟、右边的点是旁路；
  点名字开插件界面、右键是 上移 / 下移 / **旁路** / 删除；第 5 条起显示「…」并去效果器窗口；空链写「－」+
  「＋」）／声相滑条／竖直推子 + dB 读数／`M` `S`／推子右边的**竖直电平表**。
- **插入链的旁通按钮**：每行**右端 18 px** 是按钮——插件在链上时是一个亮色方块，被旁路时变暗并
  画一道斜杠（一眼能看出这一格没在工作）。**点这个方块 = 切换旁路**（一条撤销），
  行的其余部分仍然是打开插件界面；右键菜单里的「旁路」是同一件事的另一条路。
- **推子的刻度**：推子左边一栏画刻度与数字（**+6 / 0 / -12 / -24 / -40 / -60**，dB 线性，
  所以间距相等），0 dB 处还有一条横贯推子的细线；推子下面的数字框就是当前 dB 读数。
- **推子窄、电平表宽**：推子轨道 **15 px**，两根电平表各 **18 px**（条带总宽仍是 106 px）——
  演奏时要看的是表，不是推子的宽度。
- **电平表的刻度**：两根竖直条（**左 / 右**）右边一栏画刻度线与数字（0 / -12 / -40，
  另有 -6 与 -60 的刻度线）。电平表是**峰值表**，按幅度线性画，所以刻度越往下越密——
  0 dB 在顶、-6 dB 正好在一半。
- **电平表的颜色随电平变**：颜色属于**刻度**而不是属于电平——绿色在低处（-60…-24 dB）、
  黄绿到黄色在中段（-12…-6 dB）、橙到红在顶上（-3…0 dB），所以同一条表在安静处永远是绿的、
  顶上一段永远是红的，电平高起来只是**盖到更多的颜色**（`MixerWindow::getMeterColourForTest`
  就是这个色标，自检直接问它）。刻度线画在填充之上（半透明黑），顶部那截红条是削顶提示。
- 电平表是**两条**：左声道与右声道各一条，各自有峰值保持横线与削顶红条——一条轨道声像打到
  一边时，另一边会自己落下去（推子前的信号本来就是双声道）。
- 总输出条：总推子 + dB 读数 + 左右两条电平表 + 削顶红条（点电平表清掉）。
- 电平表是**峰值表**，不是响度表：音频线程只上报「这一块各声道的最大绝对值」，衰减与保持都在界面
  （`Core/MeterMath.h`：瞬间起、**每秒 20 dB 落**、**峰值保持 1.5 秒**、`|x| > 1.0` 记削顶，
  读过即清）；电平表上那条横线是峰值保持，顶上的红点是削顶。
- 条带上的每个动作都走 document：推子拖动 `beginEdit` / `notifyEdit`（**一次拖动一条撤销**，
  总推子写 `masterVolumeDb` 同样一条撤销），M / S / 插入链的增删改移也都是普通编辑。
  点条带任意空白处 = 选中那条轨道。
- **每根条带是一个真实的组件**（`MixerWindow::Strip`），它自己画自己、自己收鼠标，装在
  `Viewport` 里的普通容器里。第三十七批第一次交付时条带是「内容组件手绘 + 手写命中测试」，
  而 `Viewport` 盖在它们上面把**每一次点击都吃掉了**——推子和按钮因此完全没反应。
  现在点击、拖动、右键、滚轮都由 JUCE 正常分发，滚动与裁切也是 JUCE 的事。
- 不做：拖动重排条带、发送 / 分组 / 总线、条带里改乐器。按音轨栏顺序排，轨道增删跟着增减。

## 空格键（第三十七批）

- **所有 HM 自己的窗口**（主窗口、音色 / 效果器 / 混音台 / 插件窗口）里，空格都切换播放 / 停止：
  `MainComponent` 实现 `juce::KeyListener` 并把同一个监听器挂到每个顶层窗口上。

- 插件窗口本身（标题栏、还没加载出界面时的提示）仍然控制走带。

## 控制器栏（第三十八批）

编辑器**最底部**的一条 Cubase 式控制器栏，显示当前打开片段的一条信号：

- 位置与对齐：在画布下面，横向与网格**同一套映射**（同样的 `TimelineView::editor` 缩放与偏移；
  左边按钢琴模式的键盘缩进、右边让出滚动条，与标尺 / 标记轨一致），所以同一 tick 在网格和这一栏
  是同一条竖线。纵向画节拍 / 小节竖线，再画播放头。
- 高度与折叠：默认 **110 px**，上边缘有一条 6 px 的拖动条（往上拖变高，往下拖变矮，双击复位）；
  高度夹在 **48 px** 与「画布还剩 110 px」之间。标题行左端一个小箭头把它折成 **18 px 细栏**
  （细栏里只留箭头，与三个侧栏同一规则）。高度与折叠状态**随工程保存**
  （`EditorViewState::controllerLane`，旧工程缺字段 → 默认高度、展开）。
- 标题行：折叠箭头 → 信号下拉 → （仅自定义时）CC 号数字框 → 右侧读数（悬停显示 `tick / 值`，
  其余时候是一句用法提示）。
- 信号下拉：**常用**（力度 / CC1 调制 / CC7 音量 / CC10 声像 / CC11 表情 / CC64 延音踏板）+
  **更多**（CC2 呼吸、CC4 脚踏、CC5 滑音时间、CC65 延音开关、CC66 弱音踏板、CC67 弱音、
  CC68 连奏、CC71 共鸣、CC74 亮度、CC91 混响、CC93 合唱）+ **自定义…**（数字框输入 1–127；
  6 / 38 / 100 / 101 / 123 被拒绝——那是宿主自己发的 RPN 与 all-notes-off）。显示哪条信号是
  本次会话状态（`AppState`），不进工程。
- 值轴：0–127，`127 / 96 / 64 / 32 / 0` 五条淡参考线，数字画在画布左缘的一条窄带上
  （画在曲线之上，所以横向对位一点不动）。
- **力度模式**：每个**实际发声**的音符（含循环重复出来的）一根从底到该力度的竖条，
  被选中的音更亮。上下拖动 = 改力度（3 px 一格；多选时整组按同一差值走，一次手势一条撤销）；
  点竖条同时会选中那个音符。
- **CC 模式**：折线（2 px，线下方有淡填充）+ 折点方块（7×7）。
  空白处按住拖动 = 铅笔（一步一个折点，tick 按编辑栏的「吸附」量化，值取指针处的精确值）；
  拖折点 = 移动；右键折点 = 删除；**Shift+拖动 = 在两点之间画一条直线**（连线范围内的旧折点
  被这条线替换）；右键空白 = 小菜单「清空这条 CC 曲线」。每个手势一条撤销。
- 没有打开片段 / 打开的是音频片段时，画一句提示，不画任何东西。
- 画出来的曲线不只是画：见 `02-architecture.md` 的 CC 数据流——VST 乐器直接收 MIDI CC，
  内置乐器认 CC11（表情 → 该轨输出乘数）与 CC64（延音踏板 → 挂住 note-off）。

## 栏位尺寸与折叠（第三十六批）

编辑栏里有三个**可拖动改宽、可折叠**的栏位；它们各自的宽度与折叠状态**随工程保存**
（工程文件 `view` 段的 `panelReferenceGroupSize` / `…Collapsed` / `panelPresetSize` / … /
`panelReferenceLinesSize` / …，缺字段＝默认宽度、展开）。

| 栏位 | 位置 | 默认宽 | 最小宽 | 折叠后 | 箭头在 |
| --- | --- | --- | --- | --- | --- |
| 参考组栏 | 编辑栏最左 | 210 | 120 | 18 | 栏顶 18 px 高的箭头条，靠右端（`«` 收起 / `»` 展开） |
| 预设 / 历史栏 | 参考组栏右边（打开时） | 210 | 120 | 18 | 栏顶箭头条，靠右端（同上） |
| 参考线状态栏 | 编辑栏最右 | 264 | 120 | 18 | 栏顶箭头条，靠左端（`»` 收起 / `«` 展开） |

箭头是一个 18 x 18 的按钮（`PanelToggleButton`）：深色底板 + 描边 + 亮色尖角，**不是**画在栏的标题行里
——它占据每栏顶部一条自己的 18 px 条，所以永远压不到栏自己的按钮，也永远看得见。
栏位折叠后那条 18 px 细栏本身就是这个按钮（整条可点）。

规则：

- 拖动条宽 6 px，画在栏与画布之间；拖动**实时**改宽，悬停显示左右缩放光标，**双击回到默认宽度**。
  方向按栏的所在侧定：左边两栏**向右拖＝变宽**；最右边那栏的拖动条在它的**左**边缘，
  所以**向左拖＝变宽**。
- 行放不下时（窗口窄或栏拖得太宽）让**当前最宽的那一栏先减 1 px**，同宽的栏一起让路，
  并且**画布永远至少留 520 px**；任何栏都不会小于 120 px，折叠栏恒为 18 px。
- 折叠时该栏的内容子控件全部隐藏，**只有箭头**铺满那 18 px；点它展开回折叠前的宽度。
- 音轨栏 ↔ 编辑栏之间那根左右分隔条、音轨栏行高、编辑栏纵向缩放都不受本批影响。

## 参考组 / 参考线组编辑栏（第三十九批）

**两个编辑栏**（`Source/UI/GroupEditorPanel.{h,cpp}`）占**左边那一格**（宽沿用参考组栏的栏宽状态，
默认 210 px）：打开时参考组栏让位、历史 / 预设侧栏自动收起；`返回` 之后侧栏不自动恢复。

它们出现的三个入口，都是各行的「**编辑**」按钮：

| 入口 | 编辑什么 | 另存为存成 |
| --- | --- | --- |
| 预设栏 → **参考线组预设** 每行 | 那条预设（`PresetStore::replaceReferenceLineGroup` 覆盖） | 新的参考线组预设 |
| 预设栏 → **参考组预设** 每行 | 那条预设（`PresetStore::replaceReferenceGroup` 覆盖） | 新的参考组预设 |
| 参考线状态栏 → **参考线组** 那类行 | 工程里那一条（一次 `applyEdit("编辑参考线组")`，可 `Ctrl+Z`） | 新的参考线组预设 |

预设栏的三种行里，**历史行没有「编辑」**（那是本次会话的临时快照）；参考线状态栏的「编辑」
只对**参考线组**那一类亮，赫兹 / 选中音符频率-选中比率 / 选中多个音符三类是灰的。

栏目自上而下：

```
标题（编辑参考线组　<名字> / 编辑参考组　<名字>）
[名字输入框                 ][返回]
[锚点 <频率>　位置 <0.000>]            ← 只有参考线组编辑栏有这一行
八度线段（占满中间）
状态文字 / 颜色行 / 频率比行 / 等分行    ← 与参考组栏同一套（GroupControls）
[保存         ][另存为]
```

- **实时预览**：打开编辑栏时把副本装进工程的参考组（**派生编辑**，不进撤销栈），
  画面上立刻是这条组的线；编辑期间的任何改动也都落在它上面，撤销栈一动**不动**
  （`OctaveLadder::commitGroupChange` 在编辑栏开着时走 `applyDerivedEdit`）。
- **返回**=放弃没保存的改动（不做二次确认），把进来之前的那份参考组放回去。
- **保存**=把当前内容写回原处，并**保留**在工程的参考组上（它就是刚刚画出来的那套线），
  然后收起编辑栏；**另存为**=用名字框里的名字新建一条预设，同样收起。
- 两种模式只差画法：**参考线组编辑栏**把线段画成**一根从顶到底一样粗一样亮的直线**、
  圆点右边写**频率**（`锚点Hz × 2^(位置 − 锚点位置)`，与画布上这条组画出的线同一个数）、
  第二行标出锚点（本批只显示不能改）；**参考组编辑栏**保留分框线并照旧写比率。

### 八度线段上的框选、快捷键与叉点标签（第三十九批）

三处（参考组栏 + 两个编辑栏）共用同一套 `OctaveLadder` 行为：

- **框选**：在线段上按住拖动画橡皮筋（半透明填充 + 描边）——**圆点 / 叉点旁边也能起框**
  （每个圆点周围有 7 px 命中半径，按下之后只要真的移动就转成框选，不会被读成「点了它」），
  松手时——
  **框到的叉点一次性全部变成圆点**（一笔 `applyEdit("建立圆点")`），
  **框到的圆点同时被选中**；`Ctrl+`框选并入已有选择。只点一下不拖仍然是「清空选择」。
- **点一下 = 按下 + 原地松手**：点圆点选中它；点叉点把它变成圆点 —— 后者是**在松手时**
  才发生的（按下只记下那个叉点），所以「按在叉点旁边拖出去」不会顺手建出一个圆点来。
  从圆点上起框时，那颗圆点留在框里（按它本来就是冲着它去的）。
- **选择状态决定可用性**：恰好一个圆点时**频率比**（5 个键 + 自定义）可用；
  恰好两个圆点时**等分**可用；其余情况（多个圆点 / 没有圆点）频率比置灰，
  状态行写明原因（「已选多个圆点：只能改颜色；频率比只支持一个圆点」这类）。
  **颜色**一次作用到**所有选中的圆点**（框点跳过；两个框点共用 `frameColourIndex`）。
- **1–5 快捷键**：`1:2 / 1:3 / 1:5 / 1:7 / 1:9`，**按键盘焦点分**——
  点过参考组栏 / 编辑栏（含点圆点、叉点、空白）焦点就在它身上，1–5 归它；
  点到画布或音符编辑栏之后 1–6 又归音符编辑栏那条。启用条件同上面那条规则。
- **叉点旁的标签**：鼠标停在一个叉点旁（±7 px 命中）时，在该叉点**左侧**画一小块标签牌：
  比率产生的叉点写 **「正 1:3」/「负 1:3」**（与画布上比率箭头的文案同一个
  `music::formatRatioText`），等分产生的叉点写 **「1/N」…「(N−1)/N」**（从最低那条往上数）。
  线段上**不画箭头**——画布里的悬停箭头与「指示线」开关原样保留，两者的规则互不影响。

`GroupControls`（`Source/UI/GroupControls.{h,cpp}`）是参考组栏与两个编辑栏**共用的**中段：
状态文字 / 颜色行 / 频率比行 / 等分行（合计 89 px），所以三处的这几行不可能长得不一样。

## 编辑栏表头与「侧视」（第四十批）

编辑栏表头一行（30 px），从左到右：

| 控件 | 宽 | 说明 |
| --- | --- | --- |
| 锁定音符 | 92 | |
| 吸附 标签 + 下拉 | 34 + 78 | 下拉原为 86 px，第四十批收窄 8 px |
| 纵向取景 标签 + 下拉 | 58 + 100 | 下拉原为 110 px，收窄 10 px |
| 模式 标签 + 下拉 | 30 + 96 | 下拉原为 104 px，收窄 8 px |
| **侧视** + 小箭头 | **64 + 2 + 18** | 第四十批新增，两种模式都在；小箭头点开挑轨道的菜单 |
| 参考线显示 | 110 | 只在钢琴窗模式出现 |
| ……右端：定位选中音符 120 / 关闭编辑栏 100 | | 从右往左排 |

三个下拉共让出 26 px，为的是让「侧视」在默认 1460 px 窗口下、两种模式里都能拿到完整的
64 px（钢琴窗模式下整行 918 px ≤ 974 px 可用）。1120 px 最小窗口下表头本来就排不下
（「定位 / 关闭」在那里已经被挤没），「侧视」排在它们之前，仍然完整可见。

**「侧视」做什么**：把**其他轨道**的音符当背景板画在当前画布上。

- **点按钮 = 开 / 关；点右边的小箭头 = 挑轨道**（弹出菜单；箭头是 `PanelToggleButton`
  的 `Side::menu`，永远朝下，和面板的折叠箭头同一套外观）：

  ```
  ✔ 显示侧视          ← 等于左键那一下
  ────────────────
  ✔ 贝斯              ← 每条「能当背景」的其他轨道一行，打勾 = 要显示
    钢琴
  ────────────────
    全选
    全不选
  ```

  当前正在编辑的那条轨、以及**鼓机轨**不出现在清单里（前者就是画布上已有的轨道，
  后者是鼓垫不是音高——列出来只会让人勾了却看不到东西）。清单为空时那一行写
  「没有别的轨道可以显示」并置灰。「勾掉了哪些轨道」随工程保存
  （`EditorViewState::sideViewHiddenTracks` → `.nprj` 的 `viewSideViewHidden` 数组，
  缺字段 = 全都看；新加的轨道自动在列）。
- **只有绘制，没有任何交互**：不进命中测试、不进框选、不参与吸附与参考线计算、不参与
  自动取景，也不会被写音符的手势碰到。开着侧视时，在幽灵音符上按下仍然等于按在空白处。
- **数据来源**：遍历其他轨道（跳过鼓机轨）的片段，先按可见时间窗预筛，再用
  `music::expandClip` 取**实际发声**的位置 —— 所以**循环的片段会按周期平铺**，
  与播放 / 导出听到的一致。音频片段没有音符，自然什么都不画。
- **叠放顺序**：钢琴窗行 → 网格线 → **幽灵** → 参考线 → 片段窗口外的压暗 → 当前片段的音符
  → 拖动预览。幽灵永远在参考线与真音符之下。
- **画法**：该轨道自己的颜色（`theme::trackColour (track.colourIndex)`），填充 30% 不透明度；
  静音的音符画成 35% 的**空心描边**（和真音符「在但不出声」的语言一致）；不画备注、
  不画选中框、不画力度明暗 —— 它只是背景。
- **什么时候没有**：开关关着（默认）、打开的轨道是**鼓机**（纵向是 12 个鼓垫）或**音频**
  （画布是波形）时，这个开关置灰并且什么都不画；其他轨道是鼓机时也不画它的音符。
- **随工程保存**：`EditorViewState::sideView` → `.nprj` 的 `viewSideView`，旧工程缺字段读成关；
  它和别的视图开关一样**不进撤销栈**。

### 右键删除：选中多个时整批删（第三十九批追加）

音符与圆点的右键删除都**看选择**，不只看鼠标底下那一个：

| 右键点在哪 | 结果 |
| --- | --- |
| **多选里的**音符 / 圆点 | 整个选择一起删，**一条**撤销记录（`删除音符` / `删除圆点`） |
| **没选中**的音符 / 圆点 | 只删它自己（和以前一样，也仍然是一条撤销） |
| 空白处 / 线段上的端点（框点） | 什么都不删（端点永远不参与整批删除） |

键鼠一条路：键盘的 `Delete` / `Backspace` 与右键都走
`music::removeNotesByIds(Clip&, const std::set<int64>&)`（`MainComponent::deleteSelectedNotes()`）。

### 拖到边界时的自动滚动（第三十九批追加）

画布边缘 24 px 是**自动滚动区**，每 30 Hz 走一步、每步 12 px（`Source/UI/AutoScroll.h`）；
指针停在滚动区里时会被**钉在边界内一点**继续驱动拖动，所以拖到哪里内容就跟到哪里。
现在两个方向都有：

| 在哪儿拖什么 | 碰到 | 视图怎么动 |
| --- | --- | --- |
| 编辑栏：**移动音符**（上下拖 = 改音高） | 画布上 / 下边界 | **音高轴**滚（`centreHz` 按八度走），音符跟到画面外的音高 |
| 编辑栏：**橡皮筋框选** | 画布上 / 下边界 | 同上，于是**画面外的音高也能被框进来** |
| 编辑栏：**写音符 / 拖左右边缘改长度** | 上 / 下边界 | **不动**：这两种手势的目标（行 / 起点终点）是按下时定死的 |
| 编辑栏（鼓机轨）：拖鼓音符 / 框选 | 上 / 下边界 | **不动**：纵向是 12 个鼓垫，本来就装得下 |
| 音轨栏：**拖片段**（上下拖 = 换轨道） | 车道区上 / 下边界 | **轨道表**滚（`laneScroll`），滚出画面的轨道仍然可以落 |
| 音轨栏：建片段 / 改长度 / 拉循环 | 上 / 下边界 | **不动**（同样道理） |
| 两处：任何拖动 | 左 / 右边界 | 时间轴滚（原有行为，不变） |

参考线模式里，纵向滚动的那一步还会**重新取一次吸附目标**（`frozenLines`）：吸附到"你现在
看得见的线"，所以一条音符能一路拖到任意高的音高，而不是卡在拖拽开始时那一屏的顶线。
钢琴窗模式下同样滚动，但每步之后把半音行重新对齐（行永远是整格的）。

**框选的角锚在内容上，不在屏幕上**：起框时记下按点对应的 **tick 与频率**
（`PianoGrid::marqueeAnchorTick` / `marqueeAnchorHz`），每一次重画与重算选择都通过
`marqueeBand()` 按当前视图把它映射回屏幕（`xForTick` / `frequencyToY`）。
活动的那一角仍然跟手（它就是指针）。于是视图滚动时，框相对**音符**是停着不动的 ——
「我扫过的东西留在选择里」；如果角钉在屏幕上，视图一滚就会把已经扫过的音符重新扫出去。
鼓机轨的纵向是 12 个鼓垫、永远装得下，所以那一维直接用按下的屏幕 y。

## MIDI 输入（第四十一批）

顶栏按钮 **「MIDI输入」**（96 px，紧跟在「混音台」右边）打开一个**非模态**的
`MidiInputWindow`（标题「MIDI 输入」，设计尺寸 **900 × 560**，可缩放，经 `WindowPlacement`
放进工作区；关掉只是隐藏）。它做的是一件事：**把 MIDI 键盘上的键，绑到参考线组上的频率**。

### 窗口布局

顶栏两行：

| 控件 | 说明 |
| --- | --- |
| `MIDI设备` 下拉 | 机器上的 MIDI 输入设备 + 「（不使用）」；选择写 `%APPDATA%\NiDaw\midi.json` |
| 当前轨道名 | 弹的是**当前选中轨道**的乐器（含 VST、过该轨效果器与推子） |
| `循环` / `非循环` | 两个互斥按钮（当前模式那个亮着） |
| `循环键数` | 1–24，默认 12；只在循环模式出现 |
| `应用` | 循环模式 = 进入**学习锚点**（状态行写「请点一个左侧钢琴键，再按一个 MIDI 键」）；非循环模式只是确认 |
| `保存` / `另存为…` / `改名…` / `预设…` / `删除` | 映射进 `presets.json` 的 `midiMaps` 段；`改名…` 弹一个输入框，把**库里的那一条与工程里记的 `presetName`** 一起改掉（还没存过预设时先提示用「另存为…」）。顺序（右起）：`删除` 60 / `预设…` 74 / `改名…` 60 / `另存为…` 84 / `保存` 60 |
| 状态行 | 当前模式、锚点（`锚点 C4（MIDI 60）`）、当前组名、以及「这一轨没有频率可绑」之类的可执行提示 |

主体三栏：

| 栏 | 内容 |
| --- | --- |
| 左：**竖琴键** | 循环模式只显示这一格的 N 个半音；非循环显示 0–127（可滚动）。已绑定的键画一个小圆并写频率，空键留白（空 = 不出声也不录）。点键**试听**它绑定的频率（走选中轨的乐器） |
| 中：**连线区** | 从键拖到圆点即**加一条连线**（**磁力吸附 ≤ 14 px**）；一个键可以连好几个圆点，所以这一区一行里会把该键的**每个频率都写出来**（`261.63 Hz · 523.25 Hz`）；线的颜色用那个圆点的颜色 |
| 右：**参考线组** | 竖线与圆点，圆点右边标频率（`锚点Hz × 2^(位置 − 锚点位置)`），颜色同该组配色。这一栏**只读**（改组请回参考线组编辑栏），但它有**自己的上下缩放与滑动**（见下） |

**连线的规则（第四十一批·用户反馈后）**：

- **两个方向都能拖**：琴键 → 圆点、圆点 → 琴键，松手即绑定。
- **右栏里任意高度都算落点**：只要松手时指针在右侧那一栏里（可再往左多 40 px），
  就绑到 **y 最近的那个圆点**；14 px 磁力仍在，用作「精确命中」时的提示环。
  拖动期间画一条虚线预览 + 圆点上的环，所以「松手会绑到哪一个」在松手之前就看得见。
- **右键分三层（第四十四批）**：**右键琴键**（整行都算，包括黑键那半行右侧原来是空白的部分）
  断开这个键的**全部**连线；**右键一条连线**（点在线上，容差 6 px）只断开**那一条**；
  **右键圆点**把连到它上面的连线一次全部断开（每个键少掉的只是那一条）。
- **一个键 = 一组频率**：拖过去是**加**一条线，不是替换。弹这个键时所有连线上的频率**一起响**
  （引擎里一个键对应好几个声部），录制时也一个频率写一个音符。要清空就把鼠标移到键上右键。
  同一条线再拖一次不会重复添加。
- **右列自己的缩放与滑动（第四十四批）**：`1×` = 全览（原来的样子，整组铺满画布）；
  **滚轮**上下滑动那一列（一格 48 px），**Ctrl+滚轮**缩放（每格 ×1.15，范围 0.5×–8×，
  以指针为锚点——指哪放大哪），**双击**回到全览。滑动被夹在内容范围内，滑到边就停；
  非 1× 时栏首写一行「×2.40　双击回到全览」。左侧琴键列的滚轮照旧管自己的音域。
- **颜色**：每个圆点用的是 `参考线组` 那条状态条目的颜色（如果它设过），否则是**这个圆点自己的
  颜色**——与画布画这组线时的解析完全一致（`MidiInputState::groupColourIndex`，缺字段 = -1）。
  键上的小色条与每根电缆也用**它连的那个圆点**的颜色。竖线本身用中性色，不抢圆点的颜色。
- 右栏没有圆点时写「上面选一组参考线组，这里的圆点就是能绑的频率」；有圆点时栏底写三行提示：
  「把琴键拖到圆点上即可绑定（一个键可以连好几个圆点）；右键琴键断开这个键的全部连线、
  右键一条连线只断开那一条；滚轮上下滑动、Ctrl+滚轮缩放，双击回到全览」。

**一个八度、白键连圆点（第四十一批·第二次反馈后）**：

| 位置 | 内容 |
| --- | --- |
| 左列 | 一格 `循环键数` 个**连续半音**（默认 12，含黑键）；**每个键都写音名**（C4 / C#4 / … / B4），**没绑的步在键右侧写一个淡「空」**。键带与位置不变（13 px 一个键、整块居中） |
| 左列（方向） | **低音在下、高音在上**（与右列的频率轴、钢琴窗的键盘条同向）。一格 12 个键的方块里第 0 个键画在最下面；非循环模式同样按 `lastVisible − 音号`；滚轮往上 = 往高音走 |
| 右列 | **锚点上下各一个八度，共三个八度**的圆点（C 大调 7 × 3 = 21 个），按八度分块升序：0..6 是下八度、7..13 是锚点那个八度、14..20 是上八度。圆点右侧写频率、颜色按上面那条规则。**这一列可以上下缩放和滑动**（滚轮滑动、Ctrl+滚轮缩放、双击回全览；见上面的连线规则） |
| 右列（装不下） | 格长 M = `循环键数`；**一个八度里**第 M 个之后的圆点（以及它们在别的八度里的同一位置）**画成灰的**、不作为落点（拖过去会落到最近的装得下的那个），栏首提示「这一格只有 M 个半音，这一组的 N 个圆点装不下（把「循环键数」调大就能绑）」 |
| 状态行 | 平时：「锚点 C4（MIDI 60）　·　一格 12 个半音　·　已绑 7 个　·　空 5 个（空的不发声）」；有键连着不止一条线时后面再补「　·　一共 N 条连线」（连线数与「已绑」相同时不重复说）。学习态还没点左侧键时：「请点一个左侧琴键，再按 MIDI 键盘上一个键（Esc 取消）」；**先按了 MIDI 键**则是「先点一个左侧琴键（Esc 取消）」 |

**音高怎么走**（`midimap::Map::frequencyFor`）：`频率 = 格里的值 × 2^floor((音号 − 锚点) ÷ 格长)`。
右列给三个八度只是**选哪一个八度的频率存进格子**；弹奏时整格仍随键盘升降八度。
于是键盘从左到右是同一张音阶一遍遍往上升（C4 261.63 → B4 490.55 → C5 523.25 → …），
空格步（黑键）在任何八度都不发声。`应用` 说的是「这一格从这个键开始」：点哪个左侧琴键、
按哪个 MIDI 键，那个人就对上（`锚点 = 按下的音 − 琴键在格里的序号`，空步也能当基准）。

### 两条录制按钮（走带栏）

「节拍器」右边多了两个控件：

| 控件 | 宽 | 状态 |
| --- | --- | --- |
| `录制` / `停止录制` | 92 | 平时写「录制」，武装时写「**停止录制**」并变红（点它就是停） |
| `片段内` / `片段外` | 84 | 白字是当前落点；`片段内` 时按钮是亮色 |

顶栏「MIDI输入」右边还有 **「虚拟键盘」**（96 px，`Alt+K`）——见下一节。

`*`（主键盘与小键盘乘号）与这个按钮是同一个开关（按钮在「录制 / 停止录制」之间切换）。
武装**不会**自动起播：走带跑起来以后
按下的琴键才落成音符；停下时按下去仍然有声，只是不落。每个音（按下到抬起）是**一条**
`录制 MIDI` 撤销记录。

### 钢琴窗模式的例外

编辑栏切到**钢琴窗模式**时，MIDI 输入**绕过映射**走十二平均律（`music::piano::frequencyOf`），
窗口的状态行也写明这一点；参考线模式下才按映射走。

### 力度、踏板与表情（第四十七批）

MIDI 输入不再只认 note on/off：

- **力度**：弹下去的力度一路带到乐器与录制（录下来的音符用的是当时那个力度，不再是写死的 100）。
- **`CC64` 延音踏板 / `CC11` 表情 / `CC1` 调制轮**：与**画出来的曲线同一条路**——有外部 VST 的
  轨原样转发给插件，内置轨由引擎处理（表情乘在这一轨的输出上，所以混音台电平表跟着掉；
  踏板踩着时**实时音符的 note-off 也被挂住**，抬起才补发）。其它控制器一律转发给 VST。
- **录进片段**：录制武装且走带在跑时，这三个控制器的每一次变化都写进这一趟落点所在片段的
  **控制器曲线**（与手画的曲线同一份数据），下一条该控制器曲线在编辑栏的控制器栏里就能看到。
  撤销粒度是**一个控制器一次手势一条**（「录制控制器」）：推表情推出一串值也只算一条。

### 琶音器（第四十七批）

一行控件，**虚拟键盘窗口与 MIDI 输入窗口各一份、同一份状态**（写的是工程的
`midiInput.arp`，配置，不进撤销栈）：

| 控件 | 说明 |
| --- | --- |
| `琶音` | 开关（默认关）。开着时按下的键**不直接发声**，由琶音一个一个弹 |
| `速率` | `1/4 · 1/4T · 1/8 · 1/8T · 1/16 · 1/16T · 1/32 · 1/32T · 自由 Hz`（默认 1/16） |
| `自由 Hz` | 选「自由」时用（0.5–50 Hz），不随速度变 |
| `方向` | 上行 / 下行 / 上下 / 下上 / 随机 / 按弹下顺序 |
| `八度` | 1–4：整组往上叠几个八度 |
| `Gate` | 5–200 %：一个步里音符响多久 |
| `Swing` | 0–75 %：反拍往后推，推出一股摇摆 |
| `力度` | 固定 / 按演奏力度 / 递减（每一步 85%，一遍走完重新开始） |
| `Hold` | 松开琴键以后这一组继续跑，再按一个新键才换一组 |

**时钟**：走带跑着时步进锁在工程位置上（跟着小节与速度变），**走带停着时用它自己的时钟**
（从按下的第一个键起算）——所以不按播放也能听琶音。生成的音符走**实时音符通道**，
于是过该轨的音量与效果器、能被录制、也被踩着的踏板挂住（只作用于有音高的轨，
鼓机 / 音频轨照旧不路由）。录制时**录下的是琶音后的音符**（起始 tick 与长度取琶音的意图值）。

`VirtualKeyboardWindow`（标题「虚拟键盘」，经 `WindowPlacement`；关掉只是隐藏）。
**展开 980 × 360、折叠成 520 × 120 的小板**，自上而下：

| 部位 | 内容 |

**两种电脑键盘布局**（`布局` 下拉）：

- **常规**（默认）：下排 `Z S X D C V G B H N J M` = C…B，上排 `Q W E R T Y U` + 数字
  `2 3 5 6 7` 高一个八度；`旋律移位` 的 `±12` 就是换八度。
- **巴扬**：三排字母键按列各三个半音，所以键盘上写出来的顺序
  `q a z w s x e d c r f v t g b y h n u j m i k , o l . p ; /` 就是**一路半音往上**
  （30 个键 = 30 个半音），默认 **`w` = C4**（`q` = A3、`/` = D6）；**数字排那 14 个键**
  `· 1 2 3 4 5 6 7 8 9 0 - = Backspace` 是**低音排**：两两之间**严格交替**——
  一次上五度（`+7`）、一次下四度（`−5`），锚在 **`5` = F3**（`6` = C4），整排
  `·=F#3 · 1=C#3 · 2=G#3 · 3=D#3 · 4=A#3 · 5=F3 · 6=C4 · 7=G3 · 8=D4 · 9=A3 · 0=E4 ·
  -=B3 · ==F#4 · ⌫=C#4`（C#3–F#4）。低音的 `半音 ◀ ▶`（±1）、`五度 ◀ ▶`（±7）与
  `八度 ◀ ▶`（±12）是**独立**的一套移位（共用一个偏移量，可移 `-28 … +42`——两头刚好
  顶到 A0 / C8），两排互不影响；低音排（C#3–F#4）与旋律排（A3–D6）**有意重叠**，重叠不是冲突：
  同一个音被两条来源按着时各响一个声部（见下）。

**与硬件 MIDI 键盘完全同一条路**：鼠标点键、电脑键盘、硬件键盘都经
`MainComponent::handleLiveNoteOn/Off`，所以映射（或钢琴窗模式的十二平均律）、琶音、录制、
锚点学习、键盘高亮全部一致。**硬件弹的音在这个窗口里也亮着**（`setKeysDown`）。

**电脑键盘只在焦点落在这个窗口里时才被接管**，而且**焦点在窗口里任何控件上都行**
（第四十九批：面板自己轮询键盘，事件沿父链上浮）——打开窗口或点过「琶音 / 布局 / 力度」
之后**不必先点一下钢琴键**就能接着弹；窗口激活时面板自己把焦点拿过来。
唯一的例外是焦点在**文本框**里（力度数值框），那时按键归文本框。空格仍然控制走带。
**每条来源各自持有声部**：同一个音被旋律键与低音键（或硬件键盘与电脑键）同时按着时
**各响一个声部**、各松各停。

**键盘的读取（第五十批）**：面板在窗口**在屏幕上时**每 33 ms 按当前布局轮询一次系统的键状态
（`KeyPress::isKeyCurrentlyDown`），不再只依赖"按键事件送到面板"这一条路——按住三个键就必须
有三个声部。轮询与"100 ms 心跳"是同一个定时器上的两件事（同一个 tick 里先做差分、再做
失焦 / 文本框的兜底）。**状态行只在有电脑键按着时**多一句
`· 系统报告按下的键：Z X C`（按布局表里顺序列出，键名就是钢琴键上那个字母；⌫ 与 · 照旧）：
按住三个却只列出两个，就是**键盘自己**没把第三个键送出来（key-rolling 有限），软件侧已经证明
多少个键都能出声。不按键时状态行一字不变。

**卡音修复（第四十八批 + 第四十九批断根）**：这个窗口**自己记下它发起过的每一个音**
（按"触发源 + 音"记），移位 / 切布局 / 折叠 / 隐藏 / 关闭窗口之前先经键盘状态把它们**放掉**。
第四十九批把根因也去掉了：电脑键盘的**按键状态由面板自己轮询**（不再用 JUCE 那份按音号记的
账），并且有 **100 ms 心跳**——① 发现自己以为按着的键其实已经松开就补一条 note-off
（**漏掉的 key-up 自愈**，这正是"松开了还一直响"的来源）；② 窗口失去键盘焦点就整批放掉。
**只放这个窗口发起的音**，硬件正弹的音不受影响。

**`1–6` 让位**：虚拟键盘在屏幕上时，`1–6` 一律不触发频率比（巴扬模式下它们是低音排，常规
模式下 `2 3 5 6 7` 也在弹音）；窗口一关立刻恢复。音符编辑栏里的比率**按钮**（鼠标）不受影响，
空格 / `*` / 方向键等其它快捷键也不受影响。

- 倾斜开始/结束线可从伸出音符上下的尖端拖动，不与外侧时长边缘抢命中。
- 吸附框平时保持原来的单下拉框外观；菜单末项为 `1/n…`，只有选择它时才显示 `1/` 分母输入。
- 力度/CC 标题、网格和标尺与上方钢琴画布使用同一左右边界：左边让出琴键列，右边让出垂直滚动条。
