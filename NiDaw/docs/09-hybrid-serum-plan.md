## 二、问题归类

把剩余工作按“为什么不完成就不能算可用”分类，而不是按界面页面分类：

| 类别 | 缺什么 | 后果 |
| --- | --- | --- |
| 声音路径 | 每声部独立滤波 / 包络 / LFO；滤波包络量；陷波 / 梳状 | 多音时滤波状态串音，调制不像 Serum |
| 效果链 | 4 个 FX 槽的 DSP、存档、界面 | 目前 `fxSlots` 是空壳，用户看不到也用不了 |
| 音源编辑 | 采样起止 / 循环拖动；粒子散点与参数反馈 | 音源页只能看，不能精细编辑 |
| 调制体验 | 右键分配、宏命名、旋钮调制深度、矩阵可视化 | 矩阵能工作，但操作不像 Serum 一样直接 |
| 工作流 | 混音器页、工程文件夹、导出目录 | 大型工程的文件管理和总线操作不完整 |
| 稳定性 | 每阶段全量构建、单测、离屏自检、VST3 | 防止再次出现“界面有、声音没有” |

## 三、重排后的阶段

原则：**先把已经在代码里的半成品闭环，再动最大的声部架构；每阶段都能独立验收，不把三类风险叠在一起。**

### 阶段 A · FX 闭环（先做，风险最低）

把已经加入的 4 个 FX 槽做成真正可用的串联效果链。

1. **存档**
   - `ProjectDocument` 的 `hybrid` 段写入 / 读取 `fxSlots`。
   - `PresetStore` 的混合预设共用同一套转换函数。
   - 缺字段取默认：4 个槽全部 `none`、关闭、干湿 100%。
   - 状态：**已完成**，`Hybrid` 单测覆盖工程与预设往返。
2. **DSP**
   - 新增 `HybridFxChain`（音频线程无分配）。
   - 4 个串联槽，每槽：启用、旁通、类型、Mix、Param 1、Param 2。
   - 类型：失真、比特压碎、合唱、相位、延迟、混响、三段 EQ、压缩。
   - 位置：混合器五源混音之后、轨道插入效果器链之前。
   - 切换类型或重置工程时清空延迟 / 混响状态；参数变化只平滑，不重置。
3. **界面**
   - 混合器窗口新增“FX”页，仍在同一个 1000×760 窗口内切换。
   - 4 个槽纵向排列，可启用 / 旁通 / 换类型 / 调 Mix 与两个主参数；每个控件有中文标签和值。
4. **调制**
   - 矩阵增加 FX 1–4 的 Mix、Param 1、Param 2 目标；先接主参数，不承诺每个算法全部参数都可调制。
5. **测试**
   - 存档往返与旧工程缺字段。
   - 每种 FX 至少一条“开着与旁通输出不同”的断言。
   - 4 槽顺序、旁通、Mix=0 时逐样本等于干声。
   - 离屏自检：FX 页四个槽有真实尺寸、控件不重叠、快照新增一张。

**验收门：** 工程存盘再读回，FX 设置完全一致；旁通与 Mix=0 不改变声音；全量单测与自检通过。

---

### 阶段 B · 真正的每声部引擎（最大的一项）

这是“接近 Serum”最关键、也是风险最高的一步。必须先明确实现路径，不能直接在现有轨级滤波上继续加功能。

1. **拆出 `HybridVoice`**
   - 每个音符一个 `HybridVoice`，持有：note id、频率、力度、三个主源 + Sub + Noise 的声部状态、双滤波状态、4 个包络、4 个 LFO 相位、声相。
   - `HybridSynth` 最多 16 个 `HybridVoice`；超出时偷最老的音，并让它走快速释放。
2. **给现有音源增加“按音符单独渲染”的入口**
   - 波表 / 采样 / 粒子 / 减法各自已有 16 声部内部池。
   - 增加只在混合器内部使用的 `renderVoiceAdding(noteId, ...)`：只渲染指定 note id 的那一个内部声部。
   - 旧乐器类型继续走原来的整轨渲染入口，行为不变；混合器改走新入口。
   - 这样每个 `HybridVoice` 可以拥有自己的滤波与包络，而不必复制 16 套完整合成器。
3. **每声部处理顺序**
   - 五源按各自电平 / 声相混合；
   - Filter 1 → Filter 2（串联 / 并联 / 仅 Filter 1）；
   - 每声部音量包络与声相；
   - 汇总到轨级 FX 与插入链。
4. **每声部调制**
   - ENV 1–4、LFO 1–4、力度、键位、调制轮、宏都按声部计算。
   - 矩阵仍为 16 槽，先保持现有目标集合，FX 目标在阶段 A 已接入。
5. **兼容**
   - 旧工程只影响声音细节，不改变参数结构。
   - 单音、和弦、踏板、循环回卷、停止尾巴等既有断言必须继续通过。

**验收门：** 两个不同音高的音同时按下，各自的滤波包络互不影响；释放一个音不会改变另一个音的滤波状态；16 声部上限与偷音可测。

---

### 阶段 C · 滤波器补全

在每声部滤波骨架上补声音能力。

1. 增加陷波与梳状滤波（梳状含音高、正 / 负反馈）。
2. 把 `envAmount` 真正接入截止频率：`cutoff × 2^(envAmount × ENV2/ENV3 × 范围)`。
3. 12 / 24 dB 斜率在每种类型上语义一致；驱动放在滤波前，带输出补偿。
4. 滤波器响应图与真实参数同步；拖动截止 / 共振 / 包络量时声音和图形同时变化。
5. 测试：每种滤波类型、串联 / 并联 / 单滤波、包络量正负、键跟踪。

**验收门：** 响应图不是装饰；图上拖动的三个量都能在渲染频谱或 RMS 上测出变化。

---

### 阶段 D · 音源编辑补全

1. **单采样**
   - 波形上拖动起点、终点、循环起点、循环终点。
   - 交叉淡化长度可拖动；所有改动一次手势一条撤销。
   - 越界自动夹取，起点不得越过终点。
2. **粒子**
   - 编辑页接入实时颗粒散点：时间 × 取样位置，30 Hz，只在有颗粒时刷新。
   - 位置、扫描、粒度、密度、抖动、反向概率与图形反馈一致。
3. **Sub / Noise**
   - 保持示意波形；Sub 的八度、音量、声相与 Noise 的类型、Tone、音量、声相都有标签和值。
4. **测试**
   - 拖动后的参数、撤销、静音后散点归零、散点数量随密度变化。

### 阶段 E · 调制体验（Serum 式直接操作）

矩阵已经能发声，这一阶段只解决“怎么调得快”。

1. 旋钮右键“分配调制”，弹出 16 个槽或直接新建槽。
2. 已分配调制的旋钮显示双极深度环；拖动环改深度。
3. 宏可重命名，宏旋钮与矩阵来源同步。
4. 矩阵页支持右键删除 / 旁通、来源和目标分组显示、当前调制值指示。
5. 包络节点增加曲率拖动（如果阶段 B 的每声部包络已稳定）。

**验收门：** 不打开矩阵页也能完成“LFO → 滤波截止”的分配；所有深度都能撤销。

```
A FX 闭环
   ↓

   ↓

   ↓
```

## 五、完成定义（Relative to Serum 2）

达到以下条件即可称为“这一轮完成”，不把 Serum 2 的每一个算法都列为必做：

- 五源都能发声、能独立启用、能编辑、能存档。
- 每个音符有独立双滤波、4 包络、4 LFO；16 声部可测。
- 4 个 FX 槽可听、可存、可旁通。
- 波表编辑器支持 64 帧、64 级泛音振幅与相位、单周期绘制、2D / 3D。
- 采样可拖起止与循环；粒子有实时散点。
- 调制矩阵可通过右键直接分配，并显示深度。
- 工程能连同音频源一起搬动。
- 全量构建、单测、离屏自检、VST3 测试通过，发布包可启动。

### 明确不在本轮

- 逐项复制 Serum 2 的 Warp 模式、全部虚拟模拟滤波器、10 个 LFO。
- 频谱分析仪、颗粒窗形选择、时间拉伸同步。
- 云端预设、第三方插件扫描器重做。
